# 贴片助手

手工贴片时对着屏幕走：按料分组推进，当前位号在焊盘图上高亮，顶部显示这种料的
参数和还剩几个，空格标记已贴并跳下一个。

## 打开

页面要从 http 打开（浏览器会拦本地文件的跨源读取，直接双击 html 会看不到数据）：

```
cd <仓库根目录>
python3 -m http.server 8000
```

然后开 <http://localhost:8000/web/assembly/>。

## 操作

| 键 | 作用 |
|---|---|
| <kbd>空格</kbd> | 标记已贴 → 跳下一个 |
| <kbd>Enter</kbd> / <kbd>A</kbd> | **整组一键已贴**——这一种料剩下的全标上，然后跳下一组 |
| <kbd>Z</kbd> | 撤销上一次批量操作 |
| <kbd>←</kbd> / <kbd>Backspace</kbd> | 退回上一个，**同时取消它的已贴标记**（按错了才会退回） |
| <kbd>→</kbd> | 只往下走，不标记 |
| <kbd>S</kbd> | 跳过这个件（缺料时用），不计入已贴 |
| <kbd>F</kbd> | 翻面 |
| <kbd>0</kbd> | 复位视图 |
| <kbd>Tab</kbd> | 焊接表，逐个手动打勾／取消 |

## 整组一键已贴

一次用钢网刷完一种料、或者事后补记时用。三个入口：<kbd>Enter</kbd>、右侧
「整组已贴 N」按钮、焊接表每组组头的「整组打勾」。

**只标这一组里还没贴的**，标完弹一条绿色回执告诉你动了几个。
<kbd>Z</kbd> 撤销时也**只回滚这次标的那些**——之前手动勾过的不会被一起清掉。
一下标 23 个如果误触又回不去，代价太大，所以这条是硬要求。

鼠标滚轮缩放，拖拽平移，点板上的件或右侧位号可直接跳过去。
进度存在浏览器 localStorage 里，按版本分开，关掉再开还在。

顶部一行是**分类导航**（芯片／连接器／电感／电容／电阻…），每类带进度。
贴完电容直接点「电阻」，跳到那一类第一个还没贴的件，不用一路按空格穿过去。

## 换料卡

切到**新的一种料**时中间弹一次，告诉你去料盒拿什么：

```
        换 料
     10k   [0603]
     备料 17 颗
     C25804  电阻
```

只在换料时弹——每个位号都弹就成了噪音，而换料是唯一需要离开板子的时刻。
中途跳回贴过一半的组时按**还要贴几颗**算，不是组的总数，照总数备料会多拿。
按任意键立即消失（按键说明料已到手），否则 4.5 秒淡出；信息不会丢，
顶栏和板上 tips 一直显示着同样的内容。

## 介质

0402 的 100pF C0G 和 100pF X7R 外观完全一样，混在桌上分不回来，而 `C34`/`C35`
决定 1090MHz 检波输入高通、**必须锁 C0G/NP0**。所以介质单独做成粗体实底标签，
排在规格后面第一位，三档三色：

| | |
|---|---|
| <kbd>C0G</kbd> 青 | 含 NP0，统一显示成 C0G |
| <kbd>X7R</kbd> 蓝 | |
| <kbd>X5R</kbd> 紫 | |

介质取自 BOM 的**型号**字段，不是材质列——材质列是要求下限，型号才是实际配的料。
两者不同时会写一句「要求 X7R，配的是 C0G（向上兼容）」，因为两个介质代号并排
出现看着像数据打架。

## 一组 = 一盘料

分组键是**立创料号**，不是规格字符串。BOM 里同一个料号常按用途拆成好几行：

- `C1546` 拆成「100pF」（11 个隔直位）和「100pF C0G」（5 个射频位）→ 合成 16 个一组
- `C41432122` 那款 U.FL 座按 5 个射频口拆成 5 行 → 合成 1 组
- `C21189` 的 `ZS1` 在 PCB 上挂 `L_0603_1608Metric`（π 网络那位置可贴 0R 或电感），
  其余 0R 挂 `R_0603_1608Metric` → 同尺寸同料号，合成 7 个一组

合并后组标题只取公共前缀（`100pF`、`U.FL`），**每个位号自己的用途留在位号旁边**——
U.FL 那 5 个是不同天线口，接错就是接错天线。采购等级取最严的一档，
免得「必买指定」被合并成「已有」。

尺寸一致性用焊盘包络判断（≤1.5 倍），不用封装名——名字会因用途而不同。
把 0402 和 0603 合成一盘料是真错误，脚本和契约测试都会当场失败。

## 颜色

| | |
|---|---|
| 琥珀色 + 方框 | 当前要贴的件 |
| 蓝色 | 同一种料的其他位置（这种料还要贴哪几个） |
| 绿色 | 已贴 |
| 暗铜色 | 其他件 |
| 很淡 | 在另一面 |

B 面件会自动翻面并弹提示——不翻板照着正面图贴，会贴到镜像对称的位置上。

## 采购批次

`~/Downloads/BOM_采购清单*.xlsx` 里**一个工作表就是一批料**（采购清单 / 补 /
补2 / …）。换料卡和顶栏会显示「第 N 批」，直接去翻对应那袋。

**这是个人采购数据（含采购量、已购状态），单独输出到 `data/batches.json`
并已 gitignore，不进仓库。** 缺这个文件网页照常工作，只是不显示批次。
文件名会变成 `(2)`、`(3)`……脚本取 mtime 最新的那个，不写死。

匹配用三级判据，可靠的优先：

| 判据 | 说明 |
|---|---|
| **位号** | 采购表「规格要求」列里直接写了 `C73/C74/C75`，最强证据 |
| **料号** | 立创料号，**必须交叉验证封装**——这张表的料号列栽过跟头（2026-08-29 核出 7 处错位） |
| **规格 + 封装** | 归一化后比对 |

位号匹配也会查封装：位号是手写的，写错一个数字就会把人指到另一盘料上
（0402 和 0603 的 100pF 外观一样，拿错看不出来）。只在两边都是 4 位数字
尺寸码时才判冲突——全量比对会把电感那种「4x4mm 一体成型」vs `L_Bourns-SRN4018`
的正确匹配全部误杀。冲突时降级到下一级判据并在生成时打印警告。

匹配不上的显示「未在采购表中（多半是库存已有）」——**留白会被当成不用管**。
v4 有 28 组没匹配上，核对过：它们在采购表里根本不存在，11 个是 BOM 标注
「已有」的库存料。

## 数据从哪来

```
gen_assembly_web.py
├── .kicad_pcb                焊盘轮廓、元件外框、板框、坐标、旋转、DNP  ← 现读，永不过期
├── BOM_MASTER.csv (v4)       同料分组、材质、耐压、料号、备注
├── BOM_PURCHASE.md (v3)      同上
└── SELECTIVE_PLACEMENT.md    电源变体的选贴规则（脚本内硬编码，带断言）
```

几何一律从 PCB 当场算，不读 `render/` 下的 svg/png——那是某次导出的快照，
会比 PCB 旧，拿它当底图高亮框会指到旧位置上，而且看起来完全正常。

**改板后要重跑**（必须用 KiCad 自带的 Python，系统 python3 没有 pcbnew）：

```
~/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/Current/bin/python3 \
    hardware/tools/gen_assembly_web.py
```

页脚显示源 PCB 的日期，跟仓库里的 `.kicad_pcb` 对不上就是该重跑了。

产物契约由 `hardware/test_assembly_web_contract.py` 把关（跑在系统 python3 上）：
电源变体不能贴反、DNP 件不能混进列表、焊盘不能跑到板外。

```
/usr/bin/python3 -m unittest hardware.test_assembly_web_contract
```

## 排序

三级，按「找料成本 → 工艺 → 核对」排：

1. **元件大类**（芯片 → 连接器 → 滤波器 → 晶振 → 电感 → 二极管 → 晶体管 →
   保险丝 → 热敏 → 电容 → 电阻 → …）。手边一盒电容就一次贴完所有电容，
   不用贴两个就去翻电阻盒。大类之间仍守先大后小，大件先上板。
2. **段内按封装从大到小**（1206 → 0805 → 0603 → 0402）。工艺原则退到二级但
   仍然生效：大件对位要反复调整，周围先摆了 0402 会被镊子碰歪；逐个热风吹时
   吹外围也会掀翻已贴的小件。
3. **组内按位号升序**（D2 → D3 → D4 → D5），且**按数字比不按字符串比**，
   否则会排成 R1 R10 R11 R2，对着清单核对时看着像漏了一堆。

分类不能用 BOM 的「类型」列：两块板口径完全不同（v4 写元件类型、v3 写用途），
而且 v4 有 31 类、v3 有 37 类，做导航跟没有一样。改用**位号前缀**推导，
从 PCB 现读，跨板一致；认不出前缀的位号会让脚本当场失败，不会静默消失。

分类的粒度跟「一盘料」对齐——`ZS1` 是 0R 电阻用在 π 网络位，它和 `R21` 是
同一盘料（C21189），所以归在「电阻」里，特殊用途由位号旁的 use 标注表达。
按位号各自归类会让它单独成「匹配网络」，把电阻段劈成两截。
