本目录已有四份分别平放的STL：`case-body.stl`、`top-cap.stl`、`gps-tray.stl`、`power-plungers.stl`。默认是20×20、完整总高6.6 mm的陶瓷GPS配置。改参数后必须重新导出配套零件。

已在 Bambu Studio 02.08.02.61 真实切片，重开工程后不加载外部材料文件再次切片也通过。G-code 中 PETG 只出现在支撑接触层及擦拭塔，没有进入模型或支撑骨架。SD 主体及 D 字内岛下方的 PETG 接触层顶面为 Z19.84、19.92、20.00 mm；PLA 首层顶面 Z20.08 mm、厚 0.08 mm，因此首层底面与接触层齐平，实际竖向间隙为 0。两端 R3 低段也有接触层，部分 PETG 直接从首层落床。螺母槽及 SMA 孔保留禁支撑区。该结果证明切片路径有承托，尚未验证实物拆撑与表面痕迹。

**换料成本：**当前切片预计 5 小时 3 分 26 秒、PLA 45.98 g + PETG 18.88 g，共 64.86 g，打印中换料 32 次；原单 PLA 工程约 89 分钟、16.62 g。这里的耗材包含支撑、冲刷和擦拭塔。800 mm³ 是未校准两卷料时的保守起点，不是已验证的最小冲刷量；本方案改善接触面及拆除条件，不是省料方案。

使用前：

1. 将 PLA 和 PETG 装入 AMS lite。工程材料 1/2 是软件索引，发送前分别映射到实际 PLA/PETG 槽位，不要求必须装在硬件槽 1/2。当前 PETG 为普通 Generic PETG，未假设是 HF 或任何特定品牌。
2. 按实际料卷标注核对温度并做耗材校准。当前切片打印温度为 PLA 220℃ / PETG 255℃，床温初始 65℃、首次 PETG 后 70℃；换料冲刷宏会短时使用 240℃ / 270℃。这些是预设值，不是这卷杂牌料的实测结果。PLA/PETG 接触层方案可参考[拓竹官方支持说明](https://forum.bambulab.com/t/printing-guide-for-using-pla-basic-and-petg-hf-for-support/93273)，其中 PETG HF 的工艺参数不能直接当作普通 PETG 参数。
3. 修改耗材参数后重新切片，在“耗材”视图确认 SD 门面下方为 PETG 接触层、壳体为 PLA；保留擦拭塔及禁支撑修改器。不要把材料 2 改为 PLA 后继续使用 0 mm Z 间隙，否则支撑可能粘死。工程未发送到打印机。

这份3MF是当前默认几何及工艺的固定快照。`export_v4.py`只更新STL和预览，不自动重建3MF；修改SCAD尺寸、打印朝向、层高或支撑设置后，应重新配置并检查支撑，不能继续把旧3MF当作新模型。

## 顶部结构与装配

主盒与顶舱使用同一个圆角底板轮廓。旧顶部整墙已打开，主盒只保留两处落地玻璃支撑；SD门面、孔、浅沉槽和文字全部移到顶盖，拆盖即可开放SD区域。门面从盖的低屋面接起，两侧上轮新增斜肋已去掉，保留原有斜坡，不再复制落地的下半墙。盖靠屏幕端用斜面封合，侧面用内部导轨定位。盖固定柱与朝天面之间保留打印支撑肋。两处紧固中心X由59.25/79.25改为40/101，间距由20增至61 mm，底盒沉孔与顶盖螺母座同步移动。玻璃上侧左右内口补回R2.75圆弧（玻璃R2.5加0.25 mm间隙），保持中央仓口开放。

顶盖仍以朝天外表面平放打印。两侧朝平台的外角恢复整个90°范围的R3圆弧；主盒底板共用相同轮廓，外包围尺寸不变。圆弧低段存在悬挑，需在切片器中安排支撑，不能通过加入直线切角来代替圆角。

SD卡孔的16×3.5 mm通道及上方指尖空间保持，SD门面与顶盖一体。内置支撑及对应开关已移除，`top-cap.stl`只有一个成品实体。用户无支撑试打已观察到门面底部拉丝；后续应使用切片器支撑承托该面及文字小岛。

X+侧靠PWR/排线的玻璃支撑舌中心由Y=12移到同侧螺柱Y=5，宽8 mm减至5.6 mm；支撑高度和伸出量不变，其余玻璃舌不动。原Y=12附近让空，但实际排线路径仍须装配核对。

新增顶舱向天线方向延伸 `top_depth=20` mm（上一版为26 mm），这个方向与盒底到屏幕的厚度不同。按当前6.6 mm陶瓷模块、4 mm空气层和托盘预算，托盘背面距板边10.59 mm；设为15 mm时仅剩5.59 mm，ADS-B尾柱端至SD支架也只剩1.20 mm，因此没有把15 mm作为默认值。陶瓷的10 mm是机械预留，不能视为厂家射频要求。

默认装配外形为118.5×90.98×29.15 mm，外接GPS区与主盒厚度齐平，计入2.4 mm底板，不再为外置天线增加32.4 mm高的凸台。接口区顶边沿用 `corner_r=3`，外轮廓总宽保持118.5 mm。

1. 在桌面给拆下的盖安装三个SMA尾线接头。内侧六角止转槽按实测对边8 mm加0.3 mm对边余量设计，默认深2.2 mm；接头六角肩嵌入后，从外侧拧紧螺母。止转槽向壳内加厚，原1.8 mm穿板承压面保留。
2. 陶瓷模块按真实背面允许接触区粘到托盘的两个三角支撑上，再放入底壳止口。三角支撑已从上一版交换到另一组对角，两个切面之间净距24 mm。可从背窗或上侧缩小后的原走线口安排尾线，不要将线压在三角支撑下。贴片模式不使用陶瓷托盘。
3. 从敞开的主仓安排尾线：ADS-B先从SD低屋面下绕过左固定柱后侧，再从SD支架左侧抬入板间，AIR抬高后从SD支架与相邻玻璃支撑之间进入板间，GPS沿右边进入板间。模型仅检查直径2 mm线束的可用路径，实际线头及弯曲半径仍需核对。
4. 在陶瓷托盘塑料背框顶边的两处4×4 mm座上各贴一片约1 mm厚软泡棉；盖合后预留高度0.6 mm，泡棉压缩约0.4 mm以消隙。顶盖向下开口、四面限位的导槽包住托盘上沿1.4 mm，左右单边留0.25 mm，前后各留0.3 mm；底部止口和上槽共同限制侧摆、前后移动及翻倒。不可把泡棉贴到陶瓷片、馈点或背面元件上。先从盖内侧装入两颗M2.5螺母，再对齐内部导轨、两处玻璃支墩和托盘上沿，从上方放入盖，确认线材没有夹在接缝中。从盒底的圆形沉孔向上拧入两颗M2.5×10螺钉；内部六角窝用于螺母止转，不在外表面露出六角孔。底面沉孔默认深1.4 mm，需用能埋入的低头螺钉；实际螺钉头、螺母和SMA螺纹长度须匹配实物。
5. 安装电池、扩展板、按键销及屏幕，确认HAT自然插合、按钮回弹、SD可插拔。玻璃支撑基准和 `exp_support_adjust=0` 保持原值，不以紧固力强拉板间接头。

本版保留X+侧SW3，不支持重新启用旧Y+壁按键（`btns`必须为空）。拆盖时先断开相应U.FL并卸下底部盖螺钉，沿屏幕方向竖直抬盖2 mm释放托盘上沿，再朝天线方向移走。后缘短唇已退到玻璃外侧，不必压着玻璃硬拉盖。贴片天线粘在盖上随盖移动，陶瓷模块可留在底座托盘内。

POWER恢复旧版的嵌入式圆沉腔思路，内凸仍只有1.2 mm。直径6.6 mm、深2.2 mm的腔体同时利用原墙厚；法兰直径6.2 mm、厚1 mm，从盒内装入后埋在槽内，正常同轴工作行程也保留在槽中。PWR单独取消外侧浅凹，留0.8 mm承拉肩；USB等其他浅凹不变。导向杆直径3.7 mm，前端直径1.2 mm、长1.6 mm的细鼻后接2.2 mm粗颈，销总长仍为7.2 mm，鼻端静位及空程不变。短环内端距扩展板边缘名义4.00 mm，板子向外偏移0.20 mm后仍为3.80 mm。

该结构用槽壁包护法兰、防侧碰偏移，外肩防止向壳外脱出；与旧版一样，未装扩展板时仍能从盒内取出，并不是双向锁扣。装配时先把法兰坐入沉腔再装板，装板后检查回弹，勿强压或用胶固定活动销。

按键检查以实际开关限制的工作行程为准：最坏空程0.868 mm加开关行程上限0.20 mm，合计推进1.068 mm，并考虑导孔中的径向游动和倾斜。这是模型计算，并非实物测量；不再把未装开关时强推到1.6 mm当成安全工作状态。按键销以导向杆端贴板、细鼻朝上打印，装屏前需确认无预压、能触发且回弹正常，不要在开关到底后继续强压。

凹印深度保持 `emb_h=0.8` mm，六组文字均检查实际挖深及背面余料，1.8 mm侧墙至少保留1.0 mm。字体统一使用Liberation Sans Bold，字号2.5；USB/PWR、GPS和SD使用原字形，无横向压缩或额外扩粗。仅ADS-B/AIR使用字距1.1，字框与孔边留1.2 mm，同时避开贴片薄壁窗口和相邻孔。GPS文字中心仍为X90.5/Z19.425；PWR/USB仍共用Z9.4中心高度。

历史文字切片基线（使用切片器自动支撑，不代表无支撑试打结果）：本机Bambu Studio 02.08.02.61，A1 mini 0.4标准喷嘴、0.20 mm Standard、Bambu PLA Basic、纹理PEI、自动树状支撑30°且不限制仅底板。配置从本地预设完整解析继承，使用Classic墙生成器、外墙0.42 mm、首层0.5 mm。用户截图工艺名带星号，未展示的修改无法复现，因此验证只对应这些已知设置。该轮顶盖已实际切片：SMA文字在0.2～0.8 mm四层保留，ADS-B/AIR与孔之间的材料带保留，1.0 mm层桥接封住槽底；SD在20.2～20.8 mm四层保留、21.0 mm封底。这些字槽所在层未检测到支撑路径侵入。按屏幕侧读取的路径图文字方向正确。凹字槽底的桥接填充层不能单独用于判断文字是否消失。切片验证不等于实物打印效果保证。

## 天线参数

三种 `gps_mode`（`ceramic`、`patch`、`none`）均保留三个SMA。ADS-B/AIR按直径15 mm、外接GPS按30 mm检查，默认相邻外廓间隙约3 / 0.848 mm。外接GPS孔位与其安装面一起调整，避免只在原来约19 mm宽的区域里移动孔位。此紧凑布局不支持两根18 mm天线同时安装；改实际外径后模型会重新检查，不能据包络不相交就认定有足够的手拧空间。

外接GPS孔中心为X=90.5、Z=14.575 mm，按整个外壳厚度居中，底板也计入外部承托。直径30 mm是天线的外部包络，不是内腔尺寸；最大直径30 mm时上下各外伸0.425 mm。模型保留中央直径18 mm平面承托检查及盖/底板共同承托检查，这不是所有天线底座的通用尺寸；SMA六角止转槽、螺母和尾柱另按实际安装包络校验。

- 陶瓷：`gps_board_size=[20,20]`、`gps_ceramic_h=6.6`或`4.6`，填完整模块总厚；朝天壁1.2 mm，接收面与壁之间空气层 `gps_air_gap=4`。
- 陶瓷外形/偏移、背面元件分别用 `gps_ceramic_size/offset`、`gps_back_component_size/offset` 配置；`gps_corner_diag_clear=24` 控制两个三角内侧切面间的斜向净距。默认PCB厚1 mm、背面突出1.6 mm仍是未实测假设，接触区需按实物核对。默认两种厚度共用盒体和盖，托盘支撑高度不同。
- 背面保留14×14 mm开放窗口。原Z+走线边两端保持完整高度，只有中央 `gps_cable_slot_w=6` mm宽的区域开豁口；豁口直接开到底板上表面，深度随护栏高度与底板厚度计算（默认7.1 mm），保留完整1.6 mm底板。X-、X+及Z-三边护栏完整。已检查4×4×2.5 mm接头包络可从该局部豁口经过，该尺寸不代表所有IPEX接头。
- 防晃分两层：PCB依靠背面允许位置的胶点固定；托盘由底部止口和顶盖四面上槽共同捕获，泡棉只负责消隙。左右单边间隙0.25 mm、前后单边0.3 mm是打印装配间隙，**不贴胶、不贴泡棉的干装仍有间隙**。泡棉必须柔软、适量压缩，实际材质回弹与胶粘可靠性需试装确认。
- 模型检查三角支撑是否落在PCB范围内、是否侵入背面元件包络，以及走线口下方是否保留完整背框。原四方形胶点参数已取消。
- 贴片：`gps_mode="patch"`，按40×6×2.3 mm，朝天壁减薄至0.8 mm。10 mm机械预留不等于射频净空已经满足，需结合厂家要求和装机接收情况核对。

## 底部喇叭

默认启用 `speaker_enabled=true`，完整外廓按用户提供的26×26×4.3 mm。浅仓中心为X=90、Y=34，位于USB后方两根右侧螺柱之间；单边留0.3 mm，实际槽为26.6×26.6 mm，四角为直角，匹配喇叭方形外框，避免内圆角吃掉尖角余量。从2.4 mm底板内面下沉1.2 mm，周边及声孔网格保留1.2 mm厚度；与喇叭浅仓重叠的X84镂空已整条取消，不再留下两端残段；其余五条保持完整。设为false可恢复原底板条栅。

用户确认振膜朝盒底、宽11×高17 mm且带圆角，胶在振膜侧。安装时胶只贴振膜外围的框面，模型预留0.3 mm胶层；发声孔收在X宽11/Y高17区域，未知圆角半径按最大圆角保守内收。胶后喇叭底面Z=1.5、顶面Z=5.8，实际嵌入底板0.9 mm。出线口朝X+，与USB同向；浅仓右侧有宽2.4 mm、顶部开放的线槽通往侧墙内空带，线从上方放入，侧墙未打穿。

安装顺序为先贴喇叭、放线，再装电池和板件。电池需靠左：65×54×9.5 mm包络放在X=9.75…74.75、Y=3…57可避开喇叭及螺柱；这只是检查摆位，不是实测用户当前电池位置，电池引线也需留空。

当前正式v4.11 PCB此区域没有背面贴装器件，已经取消旧RTL-SDR外挂模块；扩展板板底Z=13.4，到含胶喇叭顶名义7.6 mm。J4穿板脚投影经过该区，实际焊脚/焊点长度未确认，不能把板平面余量当成实物已验证。喇叭背部焊片、胶厚、振膜活动余量需装前核对；尚未测声学效果。参数 `speaker_size`、`speaker_xy`、`speaker_recess`、`speaker_diaphragm`、`speaker_wire_offset` 可按实物调整，默认出线朝向保持X+。
