# 4.3 英寸外壳：v4.11 / A1 mini

源文件为 `pilot-kit-box-43-base.scad`。设备正常使用时按屏幕竖立、SD 卡所在的 Y+ 边朝天设计；GPS 天线装在壳内，接收面朝 Y+。OpenSCAD 查看时屏幕口朝 Z+，与实际使用姿态不同。

## 选择天线与导出

| 参数 | 用途 |
|---|---|
| `gps_mode="patch"` | 寒武纪 CA-G01-PA4006，按 40×6×2.3 mm 设计，局部薄壁 |
| `gps_mode="ceramic"` | 20×20 mm 陶瓷天线，顶部局部凸仓 |
| `gps_ceramic_h=4.6` | 陶瓷厚 2 mm 的款式，按总高 4.6 mm 留空间 |
| `gps_ceramic_h=6.6` | 陶瓷厚 4 mm 的款式，按总高 6.6 mm 留空间 |
| `gps_mode="none"` | 不安装内置 GPS 天线，保留三个外接 SMA |
| `part="box"` | 只导出盒体，默认选项；`print` 同义 |
| `part="plungers"` | 独立电源按键销，默认 4 个（1 用 3 备） |
| `part="plate"` | 独立云台转接板，按需打印 |
| `part="assembly"` | 装配包络预览，不能作为打印件 |
| `labels_enabled=false` | 关闭文字；默认字号 2.5 mm、浅凹 |
| `fit_glass=0.25` | 玻璃四周单边 FDM 装配间隙，首件按打印实测校准 |
| `sma_cb_d=9.5` / `sma_tail_l=12` | SMA 螺母外廓直径 / 内伸尾柱长度，按所购尾线实物校准 |
| `top_depth=17` | 顶部接口舱相对原盒体加深量，改变时会重新检查包络 |
| `glass_seat_z=28.15` | 盒底外面至玻璃内支撑面，作为固定高度基准 |
| `glass_to_screen_back=6.15` | 玻璃内支撑面至屏 PCB 背面，历史初值，独立校准 |
| `stack_h=7` | 两 PCB 相对表面间净距的历史初值，未验证为完全插合尺寸 |
| `exp_support_adjust=0` | 正值使扩展板靠近固定屏板；同时移动 J4、LED、SW3 和支撑柱，不能直接套用目测缝隙 |

两款陶瓷天线共用同一种凸仓结构，由总高参数调整空间。用户给定的 20×20 mm 优先于示例图片中的 25×25 mm；实际若含更大的底板，必须按完整底板外廓调整，而不能只量陶瓷块。

默认导出外形（不含外接天线）：

| 打印文件 | X×Y×Z，mm |
|---|---|
| `case-patch.stl`、`case-no-gps.stl` | 118.5×87.98×29.15 |
| `case-ceramic-2mm.stl` | 118.5×90.68×29.15 |
| `case-ceramic-4mm.stl` | 118.5×92.68×29.15 |

推荐从脚本导出，需本机已安装 OpenSCAD、Python 3 和原流程使用的 admesh。示例输出目录必须尚不存在，脚本不会覆盖已有打印件：

```bash
/Applications/ServBay/package/python/3.13/current/bin/python3 \
  /Users/samwu/hosts/Pilot-Kit-Box-ESP32-P4/docs/jlc/lcd-4.3in/3d-case/export_a1mini.py \
  --output /Users/samwu/hosts/Pilot-Kit-Box-ESP32-P4/outputs/case-a1mini-new \
  --images
```

脚本分别导出贴片版、两款陶瓷版、无内置 GPS 版、按键销及转接板，并写入日志和 `mesh-report.json`。遇到 OpenSCAD 错误、警告、破面、绕序冲突、错误连通数或尺寸超过 180 mm 会停止；三角面通过检查后，沿用 admesh 校正 STL 存储法线，再次核验网格。输出包围盒检查不包含切片时另加的裙边/底边。

原 `build.sh` 和 `_v2.stl/.obj` 保留作历史树脂打印流程；本次 A1 mini 使用新导出器，不使用旧脚本的结果作为验证。

## 结构与装配

USB、SW3、D8/D9 在右侧；三个 SMA 在顶部靠背板的接口区，通过 U.FL 尾线连接 v4.11 的 J2（GPS EXT）、J6（1090 EXT）、J10（VHF）。内置 GPS 接 J8。顶舱为接头、螺母和尾柱增加空间，SD 插拔保留在靠屏幕的一层。

双 USB 使用覆盖两口的统一圆角矩形穿孔（默认 11.69×10.2 mm），消除上下直边的 0.19 mm 错台；共用连续的 0.5 mm 深浅槽。PWR 和 USB 字体共用 9.4 mm 中心高度。浅槽在 D8 旁绕开 LED 的实体留边；为兼顾共同开口和留边，LED 孔径设为 1.3 mm，孔周最少保留 0.7 mm 实体。SW3 外凹直径为 6.4 mm，D9 与外凹相隔约 1.07 mm；按键导孔及内部导向结构不变。两口原有 11.5×7 mm 包胶轮廓均被新孔覆盖。统一穿孔与 D8 孔之间最窄 0.71 mm，切片时须确认这段薄壁和小孔保留。接口尺寸/高度校准若侵入 LED 留边，模型会报错。

1. 切片检查顶部接口舱和陶瓷凸仓的封顶、水平孔及按键销法兰。清理支撑后，先装 SMA 尾线和螺母，再安装 GPS 天线。螺母通过尚未装电路板的主腔操作。陶瓷天线先斜着送入，避开左上安装柱，再扶正固定；不要保持最终姿态从主腔一路平推。
2. GPS 用非金属胶固定在仓内朝天面；胶层、接头和尾线实际厚度须计入空间。不要把导电胶带、金属支架或多余线圈放在天线净空区。
3. 尾线先沿外围布置，确认不被 PCB、玻璃托舌、螺柱或电池夹住。避免直接跨越 IFA；尾线自己的弯曲半径按所购线材要求执行。预览包络不替代实际走线检查。
4. 安装电池、扩展板、SW3 按键销及屏幕组件。按键必须有静止间隙，不能依靠拧紧后挤压销子维持定位。先确认自由回弹，再通电试按。
5. 先使两板在无壳体约束时正确插合，再核对玻璃和支撑是否自然落位；不能用拧紧螺丝强拉 HAT。7 mm 板间距和 3.8 mm 铜柱只是现有模型初值，3.2 mm 是相减结果，并非已验证的隔套规格；模型也未生成这个隔套。支撑校准后需要重新匹配隔套和螺丝，不能继续固定加 3.2 mm。用户现有旧盒无法拆量，本次不要求强拆，也不据目测缝隙修改默认高度。

高度现在从玻璃往下算：玻璃支撑 z=28.15 → 屏 PCB 背面 z=22 → 扩展板顶面 z=15 → 扩展板底面/柱顶 z=13.4，柱高为 11 mm。`exp_support_adjust=0.5` 会只把扩展板和相关结构升高 0.5 mm，板间净距变为 6.5 mm，玻璃和屏板不动；这是参数含义示例，不是建议的实物补高量。`bat_h` 现在为派生量，不能再独立设置。抬高 2 mm 会使 SW3 导向套侵入屏板包络，模型拒绝生成；不能只补柱而忽略侧面接口和按钮。

## 打印起点

- 盒体按导出方向平底贴板，默认无外凸脚。按键销和云台板单独打印；不再在盒内悬挂连筋零件。
- 可从 0.4 mm 喷嘴、0.2 mm 层高开始；小字和按键销可用更细层高。先确认 Bambu Studio 预览中薄壁没有被省略。
- 顶舱封顶存在桥接，陶瓷仓和销法兰也需要逐层检查。必要时添加可从主腔取出的局部支撑；支撑可能从盒内底板生成，不能假定“仅打印板支撑”能够覆盖。未做真实切片与试打前，不宣称整件免支撑。
- 首件优先检查玻璃口、USB 插头包胶、SMA 螺纹及按钮孔的配合，再确定材料的公差补偿。默认尺寸是设计起点，不能替代打印机与耗材的实际误差。
- A1 mini 的官方打印体积为 [180×180×180 mm](https://bambulab.cn/zh-cn/a1-mini/tech-specs)。

## 已核实与仍需实物核验的边界

- 四孔与接口 XY 使用 v4.11 正式 PCB。以安装孔对齐，转换为 `x=KiCad全局x−48.75`、`y=111−KiCad全局y`；旧版 Y 映射少 1 mm。屏幕、玻璃、SD 的既有实测关系继续保留。
- `j4_ctr_z=1.6`、`led_ctr_z=0.6` 是相对扩展板顶面的可校准初值；没有用不匹配的 USB STEP 模型冒充实测高度。J4 和 H1 的外部窗口允许合并。
- D8/D9 是朝板法线发光的 0805 LED。侧窗提供观察通道，不等同导光柱；正侧面能否看清需装机确认，需要时另配透明导光件。
- 寒武纪尺寸和 ≥10 mm 净空来自用户给定资料；尚未取得厂家的净空方向定义。模型按几何包络预留空间，但不保证满足未取得的全部射频安装条件。
- IFA 的 PCB 禁铜区不是三维 RF 最低距离。塑料介质、GPS 地板、SMA 金属和尾线都可能改变装盒表现；应在最终材料和装配状态下复测 IFA，并对 GPS 做相同环境下的接收对比。不能将“网格检查通过”视为射频性能验证。
