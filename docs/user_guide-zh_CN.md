# Pilot Kit Box — 用户指南

英文版：[`user_guide.md`](user_guide.md)

本文描述当前 **4.3 寸触摸板**。旧 2.4 寸四按键载板只是
`docs/jlc/` 下的历史硬件。

## 安全边界

Pilot Kit Box 是态势感知和开发设备，不是经过适航认证的飞行仪表、导航源、
备用仪表或防撞系统。所有飞行决策必须以批准的仪表、程序、目视观察和适用
法规为准。

## 1. 板上控制与接口

| 控制 / 接口 | 日常用途 |
|---|---|
| Key3 **POWER** | 短按开机；长按约两秒关机 |
| Key1 **RESET** | 重启 ESP32-P4 |
| Key2 **BOOT** | 进入下载模式的维护按键，不是 UI 按键 |
| H1 `USB TO UART` | P4 烧录、供电和串口日志 |
| H2 `USB` | 原生 USB 2.0 HS OTG，与 J3-27/25 同网。装载板时 RTL-SDR 插载板的 USB-A，H2 空置；裸板时 dongle 接这里 |
| 触摸屏 | 全部页面导航和用户操作 |

旧 `button_task.c` 已不参与当前固件编译。Rev1.2 板上没有 MODE、TARE、UP、
DOWN 四个应用按键。

## 2. 触摸导航

屏幕边缘常驻一个悬浮按钮（FAB）。

- 点击 **☰** 展开横向 dock。
- 直接选择 **PFD、交通、列表、设置、关于、诊断**；切页后 dock 自动收起。
- 再点 FAB，或五秒无操作，dock 会收起。
- 长按 FAB 约 200 ms 后拖动；它会吸附到左/右边缘，侧边和纵向位置保存到 NVS。
- 进入诊断详情页后，FAB 变为 **←**；点击它、标题栏返回或向右滑动均可返回。
- 当前 GT911 驱动只读取第一触点，请单指操作。

### 调平姿态仪

展开 dock，长按 **调平**一秒。固件会捕获当前姿态基准并保存到 NVS。
短点只会提示“长按 1 秒调平地平仪”。

触摸 UI 没有旧 TARE 按钮的十秒工厂重置 / DCD 擦除入口。不要继续照旧
四按键说明操作。

## 3. 首次启动与罗盘校准

BNO085 校准质量持续为 0 时，屏幕会自动出现全屏“画 8 字”向导。

1. 远离扬声器、电机、笔记本、手机和大型钢制物体。
2. 握稳设备，缓慢画 8 字，并让设备经过多个不同姿态；不要只绕单轴旋转。
3. 持续到精度至少达到 2 且保持稳定，向导会自动退出；点“稍后再说”可跳过。
4. 把已安装设备放到正常水平姿态，展开 dock，长按“调平”一秒。

BNO085 会在设备运动时持续修正磁场校准。调平保存的是 Pilot Kit 软件姿态
参考，与 BNO085 内部校准状态不是一回事。

当前固件假定 IMU 模块竖直安装：芯片面朝飞行员、排针位于飞行员左侧、
VCC 在顶部。若实际安装方向不同，必须修改并验证固件安装变换；单靠调平无法
修复错误的轴向映射。

## 4. 主要页面

| 页面 | 内容与操作 |
|---|---|
| **PFD** | 姿态、俯仰/坡度、航向/HSI、地速、气压高度/升降率、GPS 和交通状态 |
| **交通** | 360° 交通雷达；点击量程/方向控件和目标查看选择或详情 |
| **列表** | 已跟踪飞机表；点击表头排序，拖动滚动，点击行展开详情抽屉 |
| **设置** | 语言、QNH、地图方向、量程、日志后端和 MicroSD 格式化 |
| **关于** | 项目版本、构建信息和硬件摘要 |
| **诊断** | SDR/DSP、BLE、GPS、IMU、气压计、存储、温度等实时卡片；点击卡片进入详情 |

dock 只切换六个一级页面；详情页不会再出现第二套导航 dock。

### 存储设置

选择 MicroSD 日志后端后，下次启动才生效。启动时没有可用卡会在本次启动
回退到 LittleFS。格式化采用五秒内二次确认；当前日志正在写卡时会拒绝格式化。

## 5. 外接模块行为

- **RTL-SDR：**装上 Pilot Kit 载板时，dongle 插载板的 USB-A 插头
  （J3-27/25），H2 保持空置；裸板时用合适的 USB-C OTG 转接头或有源
  Hub 接 H2。两者同网，只能占用其中一个。H1 不是 SDR 数据口，P1 也不是
  USB。
- **BNO085：**当前驱动轮询地址 `0x4A`；INT 已接 GPIO34，但固件未使用。
- **BMP388：**当前驱动轮询地址 `0x76`；INT 已接 GPIO31，但固件未使用。
- **GPS：**UART1 使用 P4 TX GPIO49、P4 RX GPIO51，9600 8N1；时间来自
  NMEA RMC，当前固件不使用可选 GPIO50 PPS 接线。
- **BLE：**新板需要经 P1 一次性烧录 C6 ESP-Hosted slave。参见
  [`hardware/c6_slave_firmware-zh_CN.md`](hardware/c6_slave_firmware-zh_CN.md)。

## 6. 常见问题

| 现象 | 检查 |
|---|---|
| 无画面或无背光 | 确认供电稳定，复位后通过 H1 查看显示日志 |
| 触摸无响应 | 确认 GT911 在 `0x5D` 或 `0x14` 被识别；出厂 TP_INT 开路，固件使用轮询 |
| 触摸旋转或偏移 | 确认日志为逻辑 800×480、PPA 顺时针 90° |
| 航向响应错误 | 先核对 IMU 实际安装方向，再画 8 字校准并执行调平 |
| 交通页没有本机位置 | 把 GPS 天线移到开阔天空下等待定位 |
| RTL-SDR 不枚举 | 确认插在载板 USB-A（裸板则 H2）而不是 H1/P1，且两者只占用一个；必要时换有源 Hub |
| MicroSD 仍提示重启 | 保持卡插入并重启；缺卡或坏卡会回退 LittleFS |
| BLE 不广播 | 完成 C6 一次性烧录，并检查 ESP-Hosted 是否在 DSI 前启动 |

接口脚号和电气注意事项见
[`hardware/board_pinout-zh_CN.md`](hardware/board_pinout-zh_CN.md)。
