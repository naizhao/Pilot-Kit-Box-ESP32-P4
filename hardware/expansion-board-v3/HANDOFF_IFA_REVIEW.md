## 1. 【硬事实】可独立验证的原始数据

这一节的每一条都能从文件或实测记录复现。**这是唯一可信的地基。**

### 1.1 三块实板的 NanoVNA 实测（用户亲测）

测量链路：`U.FL → SMA pigtail 100mm` + `SMA公-SMA公 200mm` → NanoVNA。

| 板 | 叠层 | 实测 |
|---|---|---|
| **V1**（120×80，PCB1，2026-05-31 打样） | 2 层 | **867 MHz**，SWR **1.197**，Z = 43.75 + j5.637 |
| **V2**（100×60，Waveshare 4.3，2026-07-31 打样） | 2 层 | **1408 MHz**，SWR **1.681**，Z = 30.33 + j5.617，驻波图毛刺多 |
| **V3.2**（当前打样实物，6 层） | 6 层 | **原始状态测不出参数**，只读到 R ≈ 25.79Ω |

**V3.2 实板改造实验**（用户在实物上动刀，每步受控）：

| 状态 | 频率 | SWR | 阻抗 |
|---|---|---|---|
| ① 原状（两腿都埋在铺铜里） | 测不出 | — | R = 25.79Ω |
| ② 切开短路腿 + 6mm 铜线引地 | 1250 MHz | 1.7 | 57.56 + j28 |
| ③ 上述焊到 GND 并装 3D 打印外壳 | **1220 MHz** | 2.0 | 38.70 + j28.4 |
| ④ 再在开路端焊 0.2mm × 27.7mm 跳线（悬空约 2mm） | 1080–1090 MHz | 2.0+ | ≈30Ω |

② 的做法：沿腿划出与馈线腿一样的形状分界，**并把过孔一起切断**（短路腿的过孔在腿中间，
不切过孔的话腿的上半截照样通过它全部接地）。实际短路腿比馈线腿略短一个过孔位。

### 1.2 gerber 一手几何（可用脚本复现）

源文件：`~/Downloads/jlc backup/` 下两个 JLC 打样 zip。
解析脚本：`tools/ifa_gerber_parse.py`（⚠️ D 码是老式 `G54D12*`，坐标 `%FSLAX45Y45` 除以 1e5）。

**V1**（板框 120×80）：
```
主臂   (8.805, 77.616) → (64.805, 77.616)   1.5mm 宽   56.000mm
馈电腿 x=59.805, y 71.616→77.616             6.000mm
短路腿 x=64.805, y 71.616→77.616             6.000mm
两腿中心距 D = 5.000mm
焊盘 1.5×1.5 @ (59.817,71.628) 与 (64.805,71.651)
接地路径：腿末端 → 0.254mm×4.396 → 0.508mm×9.628 → 进地平面 (61.976, 58.420)
          接地引线共 14.024mm
馈线：焊盘 → 0.254mm × 2.556mm → U.FL 信号焊盘 (61.976, 68.937)，尺寸 1.0×1.05
天线区上下全镂空：底层 0 段走线，3 个填充区最大那个 y 只到 64.8（天线在 71.6~77.6）
主臂上沿到板边 1.634mm；开路端到板边 8.055mm
天线正下方(x 8.8~64.8)地平面上沿 y = 60.292 → 主臂离地 17.324mm
```

**V2**：
```
主臂 39.488mm 中心线（铜箔包络 40.988 ≈ 常说的「41mm」）
腿 6.000mm，D = 5.000mm
接地引线 1.466mm，终点 (65.763, 58.443) 直接进顶层铺铜
主臂离地 4.118mm
顶层大铺铜与天线区重叠
```

> ⚠️ **追接地路径时容差不能小于 0.45mm**：跨线宽变化处（0.254 接 0.508）两段端点
> 坐标不重合（V1 那里差 0.395mm），容差 0.06mm 会在那里断掉，把 14.024mm 追成 4.396mm。
> 上一位就这么错过一次。

## 2. 【历史输入】上一位的推导链

**以下内容是当时送审的推导，不是当前结论。**独立 HFSS + V1 双点校准结果见文首链接。

### 2.1 谐振长度口径与常数 K

主张：`L = 主臂中心线 + 腿 + 接地引线`，一直算到电流真正进入地平面那一点。

```
V1  56.000 + 6.000 + 14.024 = 76.024mm × 867MHz  = 65,913 MHz·mm   εeff 1.293
V2  39.488 + 6.000 +  1.466 = 46.954mm × 1408MHz = 66,111 MHz·mm   εeff 1.285
                                          差 0.3%              差 0.6%
取平均 K = 66,012 MHz·mm
```

**请复核**：
- 这个口径（把接地引线计入谐振长度）在 IFA 理论上是否成立？
- 两个点拟合出的「常数」，0.3% 的一致性是否可能是巧合？（只有两个数据点）
- εeff 1.29 对「2 层 FR4、天线区上下全镂空」是否合理？

脚本：`tools/ifa_calibrate.py`

### 2.2 由 K 外推 v4 长度（已否决）

```
装盒目标 1090MHz → 装盒态 L = 60.561mm
装盒下移 2.5%（V3.2 实测 1250→1220）→ 裸板目标 1117MHz → L = 59.11mm
腿保持 6.0mm → 主臂中心线 53.11mm（铜箔包络 54.61mm）
画长待切：画 55.11mm，出厂从开路端切 2mm
dF/dL：L ±1mm → 频率 ∓18MHz
```

**请复核**：
- 「装盒下移 2.5%」由 V3.2 一组数据得出（1250→1220），能否用于 v4？
- 2 层板标定的 K 用到 6 层板上，前提是「天线区上下全层镂空时介质环境几乎相同」
  （2 层板厚 1.6mm vs 6 层 1.54mm）。这个论证是否成立？

### 2.3 接地引线与输入阻抗的关系

```
V3.2 原状    引线≈0（腿中途入铺铜）   R 25.79Ω
V2           引线 1.466mm             R 30.33Ω
V3.2+飞线    引线 6mm（悬空铜线）      R 38.70Ω
V1           引线 14.024mm            R 43.75Ω
V3.2 切断    不接地                   R 57.56Ω
```

主张：五点单调，斜率约 1.07 Ω/mm，引线电感抬高 R。

**请复核**：
- 这五个点里有三个来自同一块板的改造过程（V3.2），能否与 V1/V2 混在一起拟合？
- **另有外部意见认为 R 只由 D（馈电脚↔短路脚间距，即抽头位置）决定。**
  但三块板的 D 全是 5.0mm（V3.2 是 4.988），R 却从 25.79 到 43.75。
  请判断哪个模型更站得住，或者两者如何统一。
- V1 的 h（主臂离地 17.324mm）与引线长度在数据上共线，**分不开**。

### 2.4 当时提议的 v4 参数（已否决，未实施）

```
拓扑：短路腿走到净空区边缘直接扎进 GND；馈电腿末端也在边缘，
      出边缘立刻是有 In1 参考面的 50Ω 微带；净空恰好包住天线本体
腿 6.0mm   主臂中心线 53.11mm（画 55.11 切 2mm）   D 5.0mm（中心线↔中心线）
净空 2.0mm   馈线 0.15mm + 1.5mm taper（1.5→0.15 渐变）
预期 R ≈ 24~26Ω，靠 π 网络（ZP1/ZS1/ZP2）拉到 50Ω，Q ≈ 1.0
板面占用：纵向 8mm（占 62mm 板高 13%）；横向 60.61mm（占 100mm 板长 61%）
```

当时的图曾由`tools/draw_ifa_v4c.py`生成；该脚本和`build/ifa_v4c.png`现已更新为
50.2/52.0mm当前预研方案，**不再是本节53.11/55.11mm历史输入的配图**。

**请复核**：
- 横向 60.61mm 比 V3.5 的天线包络（46.50mm）长 10.11mm，是否可接受？有无更省的拓扑？
- R≈25Ω 交给 π 网络，**这在 V1/V2 上从未验证过**（它们都是天线直接接 U.FL，没有匹配网络）。
- 净空 2.0mm 是否足够？（见 3.7 的争议）

## 3. 【重要】上一位犯过的错误清单

**列出来是为了让你知道他在哪些地方翻过车，请重点检查这些方向。**

| # | 错误 | 性质 |
|---|---|---|
| 1 | 把 **2.4 板**的禁铜区当成 4.3 板的，得出「纵向漏抄 13.4mm」的错误结论 | 认错板子 |
| 2 | 拿 **V3.2 改造态**（切腿+外接飞线+装盒）的 1220MHz 反推**设计几何**的 f·L 常数——输入几何与输出几何不是同一个东西 | 数据口径 |
| 3 | 谐振长度**漏掉接地引线**，两块板 f·L 差 19.1%，他把这个离散度解释成「地平面形态不同造成的物理差异」。加上引线后差 0.3% | 口径错 + 用看似合理的解释掩盖 |
| 4 | 追接地路径**容差设 0.06mm**，在跨线宽处断掉，14.024mm 追成 4.396mm | 工具参数 |
| 5 | 推荐 A 方案（14mm 接地引线），**它把地平面上沿推远，逼馈线在无 In1 参考面的净空区里裸奔 14mm** | 结构性缺陷，外部指出 |
| 6 | 推荐腿 17mm，论证是「V1/V2 的 h 差 4.2 倍而 K 只差 0.3%」——**但两块板变的是引线，腿都是 6.0mm**，那组数据没有触及腿长这个变量 | 逻辑漏洞（拿 A 的证据证 B） |
| 7 | 同上，**17mm 腿在 62mm 板高上根本摆不下**，提方案前没有对着板框验算 | 流程错误 |
| 8 | openEMS 模型是给 **V3.5** 建的，跑 V1/V2 时只改主臂长度、**地平面形状完全没换**，而地平面是 IFA 辐射体的另一半 | 建模错误 |
| 9 | 仿真脚本定义了 `FINE = 0.12` 却从未使用，全板 0.6mm 网格，比 0.254mm 的引线还粗 | 代码 bug |
| 10 | 等效 Dk 统一取 4.5 并称「四叠层自洽」，**实际每个叠层不同**（2层 4.42 / 4层 4.52 / 6层 4.73）；6 层 50Ω 线宽推算 0.158mm，官方正算是 **0.1509mm**，偏粗 4.6% | 已由并行 session 在 `d5591ef` 修正 |
