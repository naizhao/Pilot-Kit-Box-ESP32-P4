# 扩展板 V1 — PCB 布局布线约束（阶段 4 依据文件）

> 板厂/叠层锁定：嘉立创 4 层 **JLC04161H-7628** 阻抗叠层（1.6mm，外层 1oz，L1-L2 介质 7628 约 0.21mm）。
> 50Ω 单端微带线参考线宽 **0.15mm**（嘉立创官方阻抗计算器实算：JLC06161H-3313，L1 参考 L2，
> 介质 3313 0.0994mm/Dk4.1 → 0.1509mm = 50.00Ω）。
>
> ⚠️ 旧值 **0.34mm 是 4 层 JLC04161H-7628**（L1-L2 介质 0.21mm）的。`96fc34e` 转 6 层后介质
> 薄了一半多，同一线宽实测只有 **31.82Ω**（官方计算器反算），偏低 36%。失配的馈线不只是损耗，
> 它会把天线的谐振读数一起拖走——2026-08-21 查 IFA 时才发现。
> **下单必须勾「阻抗控制」**，0.15mm 已属细线，不勾没有 ±10% 保证。
> 层规划：**L1 信号+RF / L2 完整 GND（禁止分割）/ L3 电源 / L4 信号**。

## 0. 工程内已固化的规则（`.kicad_pro` net_settings）

| 网络类 | 线宽 | 间距 | 归属网络 |
|---|---|---|---|
| RF50 | **0.15mm** | 0.15mm | 27 条：ANT_1090/978、LNA/SAW 各级、DET_*、SUBG_RF*/N3-N5、GNSS_RF、SW1_J* |
| POWER | 0.5mm | 0.2mm | 2 条：USB_VBUS、VCC_5V |
| POWER_LO | 0.25mm | 0.15mm | 9 条：三路 3V3、RP_1V1、SUBG_VDDR、四路熔丝后馈电 |
| Default | 0.15mm | 0.15mm | 其余 |

> ⚠️ **RF50 是 0.15mm，不是 0.34mm。** 0.34 是四层板 JLC04161H-7628（L1–L2 介质
> 0.21mm）的 50Ω 线宽；本板转 6 层后 L1–L2 只有 0.0994mm，同样 0.34mm 宽实测反算
> 只有 **31.82Ω**。失配的馈线会把天线的谐振读数一起拖走。详见 `IFA_ANTENNA.md` §3。
>
> 这张表本身长期与 `.kicad_pro` 脱节过（Default 写 0.2 实际 0.15、POWER 间距写 0.15
> 实际 0.2、漏掉整个 POWER_LO 类）。**冲突时以 `.kicad_pro` 的 net_settings 为准。**

⚠️ **RF50 的 clearance 必须保持 0.15mm**，不可设成 0.3mm：0.5mm pitch 的 QFN48/DFN-8
封装内部相邻焊盘天然只有 0.22–0.25mm 间隙，设大会产生无法满足的 DRC 报错。
**共面波导（CPWG）的信号-地间隙是布线时按阻抗计算器设定的几何参数，不是网络类最小间距。**

## 1. 总体分区（俯视，J3 排母面向主板）

```
┌────────────────────────────────────────────────────────────┐
│ J1(2×20 排母, 与主板 J3 对插)          GNSS 区: U7+J2(U.FL) │
│ 电源区: U1-U3 LDO                      [尽量远离 RF/DCDC]   │
│ 传感器区: U4(BNO085) U5(BMP388)                             │
│   QMC5883P → 磁洁净区(距电感/DCDC/大电流环路 ≥10mm)          │
│ RP2040 + Flash + USB-C(板边)     CC1312R 区: U10+匹配+J5    │
│ ── 1090 RF 链（沿板边一条直线，严禁折返）─────────────────── │
│ J6(U.FL)→偏置Tee→U11→FL1→U12→FL2→TJ1→U13/U14→切片器→(PULSES→RP2040) │
└────────────────────────────────────────────────────────────┘
```

## 2. 1090 RF 链（最高优先级）

1. **链路直线布置**，输入到检波器单向推进，任何一级不得跨越另一级上方/下方走线。
2. 全链 50Ω 受控阻抗（L1 层，参考 L2 GND）；级间连线尽量短（目标每段 <8mm）。
3. **级间隔离**：LNA①输入段与 LNA②/检波段用 GND 过孔墙分隔（过孔间距 ≤λ/20@1.09GHz ≈ 2.5mm，实操 1.5mm 栅栏）；SAW 输入/输出两侧不得平行走线。
4. TA0970A 的 A 长地焊盘（2.2mm）下方打 ≥3 个 GND 过孔。
5. AD8319/AD8313 双封装位：**共享同一段输入走线末端，两封装背靠背放置**，EP/COMM 就近多过孔接地；RTADJ(R20)、52.3Ω(R19) 紧贴引脚。
6. MM8930 产测座：land/阻焊严格按 O30E 标准图（封装已按原图复核；DFM 阶段再核阻焊细节），两侧 50Ω 渐变线按图收窄至 0.8mm 馈线宽。
7. 检波器输出（RF_DET_OUT）之后是"准模拟低频区"：切片器 RC 网络紧凑放置，远离 PULSES 数字回程；LEVEL_BIAS/RSSI 走 L4 无妨。
8. 屏蔽罩预留：RF 链 LNA①→检波段外围画 TE 2118716-2 框（16.5mm）丝印+焊盘，V1 不焊罩。

## 3. 978 段

1. CC1312R 的 lattice balun（L9/L10/C40/C44）元件对称紧贴 RF_P/RF_N 引脚，差分段 <5mm。
2. DCDC 电感 L7（6.8µH）与 C60 紧贴 pin33，"低电感接地"（TI 原注）——C60 地过孔 ≥2 个直下 L2。
3. **L7 属于磁洁净区排除对象**：与 QMC5883P 距离 ≥15mm。
4. 48M 晶振走线 <5mm，包地；32k 晶振远离 DCDC 开关节点。
5. J5 附近 D3(ESD) 先于 C39 靠天线端。

## 4. 三天线口与共存

- J6(1090)/J5(978)/J2(GNSS) 三个 U.FL **分置三个板角**，彼此间 GND 过孔墙。
- GNSS RF_IN 走线独立短直，远离 RP2040 QSPI（谐波密集）与 USB。
- 偏置 Tee 的 PMOS/保险丝/100nH 属直流侧，放 RF 线背面区域（L4）亦可，馈电点过孔进 L1。

## 5. 数字区

1. RP2040：QSPI Flash 走线 <15mm 等长不强求；晶振包地；USB DP/DM 90Ω 差分（0.2/0.2 参考 JLC 表）短直到 USB-C。
2. PULSES（比较器→GPIO19）是关键采样信号：单根短直、包地，不与 QSPI/USB 平行。
3. SUBG SPI + cJTAG 束走 L4，长度不敏感（≤10MHz）。
4. USB-C 开口方向：**待外壳干涉检查**（docs/jlc/lcd-4.3in/3d-case 的 v2 薄壁盒），先按板右侧边缘出口布置。
5. J1 排母 40 脚全部过孔直通，孔位与微雪 J3 逐脚镜像核对（HAT 对插方向！画板后用主板实物比对一次）。

## 6. 电源与地

1. L2 整层 GND 不分割；RF 回流全部走 L2。
2. 三路 LDO 分区供电：3V3_RF 走线单独从 U2 拉到 RF 链，不与 3V3_DIG 共享路径；各芯片去耦电容 0402 贴脚。
3. BMP388 上方外壳留通气孔（结构侧动作，板上无铜即可）。

## 7. 磁洁净区（QMC5883P）

- 与以下保持距离：L7 DCDC 电感 ≥15mm、任何 >100mA 电流环路 ≥10mm、螺丝孔/钢件 ≥8mm。
- 传感器下方四层禁走大电流；参考地完整。

## 8. 板框与结构（V1 占位，待外壳干涉复核）

- 板框先按 **100×60mm** 起步；J1 排母位置与微雪载板 J3 相对位置逐脚对齐（关键！）。
- 固定孔 4×M2.5，位置避开磁洁净区。
- 外壳开孔（USB-C、三个 U.FL）与 3d-case v2 的干涉检查 = 投板前置门。
