# V3.2 裸板验收测试

> ⚠️ **阶段 1、2 必须在贴片之前做完。** 贴了片以后，去耦电容和芯片内部通路会
> 并联在电源和地之间，电源对地读数不再是开路（会是几百欧到几 kΩ，还会因为电容
> 充电一直漂），那时候就分不清是板子坏了还是芯片正常吃电流。
>
> 裸板测出问题 → 找嘉立创换板，损失就是几天时间。
> 贴完片才发现 → 连料带工白搭一套。

板子数据（全部实取自 `kicad/expansion-board-v3.kicad_pcb` 和 `fab/gerber/`）：

```
6 层    F.Cu(信号) / In1(GND) / In2(信号) / In3(3V3_DIG 平面) / In4(GND) / B.Cu(信号)
板厚    1.6mm 标称（嘉立创下单页提示实际结构 1.5384mm，在 ±10% 内）
过孔    452 个 ⌀0.30mm，正反面盖油
PTH     另有 4 个 ⌀0.60mm
NPTH    4 个 ⌀2.70mm（安装孔）+ 2 个 ⌀0.65mm
元件    156 个，全部在顶层，底层无元件
```

## 关于「过孔看不见孔」

**这是正常的，不是缺陷。** 板规里明确设了过孔两面盖油：

```
(tenting (front yes) (back yes))    ← 过孔正反面盖绿油
(covering (front no) (back no))     ← 没有做树脂塞孔
```

所有多层板都这么做，原因有两个：

1. **防盗锡**——过孔不盖油，回流焊时旁边焊盘的锡会顺着孔被吸走，造成虚焊
2. **防短路**——0.3mm 的裸铜孔露在外面，装配时掉进一根锡丝就短路

盖油只盖表面那层，**孔壁的镀铜是通的**。对着强光看，盖油的过孔会透出一点亮点；
用指甲划过能摸到一个个小凸起。

真正肉眼能看见的孔是那 4 个 ⌀2.7mm 安装孔——它们是 NPTH（非金属化），孔壁没有镀铜。

要确认过孔到底通不通，别靠看，做下面的**阶段 2**。

---

## 阶段 0：目视 + 量尺（5 分钟）

- [ ] 4 个 ⌀2.7mm 安装孔都在，孔内壁是板材本色（不是铜色）
- [ ] 卡尺量板厚，落在 **1.44 ~ 1.76mm** 内（1.6 ±10%）
- [ ] 背面丝印版本号是 **V3.2**，不是 V3.1 或 V1.0
- [ ] 板边无分板毛刺、无分层白边
- [ ] 阻焊层无划伤露铜，尤其 QFN（U8/U10）周围
- [ ] 焊盘表面平整、无氧化发黑（无铅喷锡应该是均匀的银白色）

---

## 阶段 1：电源对地绝缘 ⚠️ 最关键

**万用表用电阻档，不要用通断档**——通断档只会"响/不响"，看不出 100kΩ 这种半短路。

裸板上这些**必须全部开路**（读数 ∞ 或 >10MΩ）：

| 测这两点 | 探哪个焊盘（挑的是大焊盘，好下探针） | 期望 |
|---|---|---|
| GND ↔ VCC_5V | `U10.49`(5.2mm 散热焊盘) ↔ `J1.1` | 开路 |
| GND ↔ 3V3_DIG | `U10.49` ↔ `U9.8` | 开路 |
| GND ↔ 3V3_RF | `U10.49` ↔ `U14.1` | 开路 |
| GND ↔ 3V3_GNSS | `U10.49` ↔ `Q2.2` | 开路 |
| GND ↔ RP_1V1 | `U10.49` ↔ `C28.1` | 开路 |
| GND ↔ SUBG_VDDR | `U10.49` ↔ `C60.1` | 开路 |
| VCC_5V ↔ 3V3_DIG | `J1.1` ↔ `U9.8` | 开路 |
| 3V3_DIG ↔ 3V3_RF | `U9.8` ↔ `U14.1` | 开路 |

> `U10.49` 是 CC1312R 的 EP 散热焊盘，5.2×5.2mm，是全板最好探的 GND 点。

**任何一对读数低于 1MΩ 就停手**，是层压错位或钻孔毛刺，直接找嘉立创换板，别贴片。

## 阶段 2：网络连通 —— 顺便验证那 452 个过孔

用通断档。下面每一对的连接路径都**必须穿过内层或底层**，也就是说测通了就等于
证明过孔是通的。这是验证过孔最直接的办法（比拿放大镜看强）。

### 电源网络（跨整块平面，验证 In3 电源层和 In1/In4 地层）

| 网络 | 测这两点 | 距离 | 走线层 |
|---|---|---|---|
| GND | `J5.2` ↔ `J4.SH` | 94mm | In1 + In4 |
| 3V3_DIG | `R3.1` ↔ `C65.1` | 76mm | **In3 电源平面** |
| 3V3_RF | `C52.1` ↔ `C38.1` | 82mm | F + In2 + B |
| 3V3_GNSS | `U3.5` ↔ `R18.1` | 70mm | F + In2 |
| VCC_5V | `C2.1` ↔ `D1.1` | 34mm | F |

> **3V3_DIG 那条要重点看。** 这块板的 In3 是 3V3_DIG 电源平面，设计过程中出过
> 「平面上走信号导致铜皮碎成 14 块」的问题（已修）。实板测这两点，是对修复结果
> 的最终验证。

### 信号网络（每条都跨 ≥2 个铜层，必然经过过孔）

| 网络 | 测这两点 | 距离 | 走线层 |
|---|---|---|---|
| RF_DET_OUT | `R35.1` ↔ `U13.5` | 81mm | F + In2 + B |
| LEVEL_BIAS | `R33.1` ↔ `C49.1` | 53mm | F + In2 + B |
| GNSS_TXD | `U7.2` ↔ `J1.36` | 50mm | F + In2 |
| USB_CC2 | `R8.1` ↔ `J4.B5` | 50mm | F + B |
| BIAS_EN_1090 | `R18.2` ↔ `U8.4` | 50mm | F + In2 |
| SUBG_TMSC | `U10.24` ↔ `U8.27` | 44mm | F + In2 + B |
| BIAS_EN_978 | `Q2.1` ↔ `U8.5` | 44mm | F + In2 + B |

全部应该 **<1Ω 导通**。挑其中 4-5 条测就够，不用全测——过孔是同一道工艺出来的，
抽样代表性足够。

## 阶段 3：贴片回来之后

裸板过了以后再做，这里先列出来，到时候展开：

1. **上电前**再测一次阶段 1 的电源对地——这次不该是开路了，但也不能是 0Ω。
   短路（<10Ω）说明贴片时有连锡。
2. **限流上电**：实验电源限流设 100mA，5V 加到 `J1.1`。正常应该只吃几十 mA。
   一上电就顶到限流 → 立刻断电查短路。
3. **分级量电压**：`3V3_DIG`(U9.8) / `3V3_RF`(U14.1) / `3V3_GNSS`(Q2.2) /
   `RP_1V1`(C28.1) / `SUBG_VDDR`(C60.1) 逐个量，都在标称 ±5% 内。
4. **RP2040 枚举**：USB-C 插电脑，按住 `SW2`(BOOTSEL 焊盘，镊子短接) 上电，
   应该出现 RPI-RP2 U 盘。
5. **调试口**：`TP1`(SWCLK) / `TP2`(SWDIO) 接调试器。
6. **解调输出**：`TP3`~`TP6` 是 DEMOD0-3，`TP7` 是 RECOVERED_CLK，接示波器。

### 测试点速查

```
TP1  SWCLK           TP5  DEMOD2
TP2  SWDIO           TP6  DEMOD3
TP3  DEMOD0          TP7  RECOVERED_CLK
TP4  DEMOD1
SW1  RP_RUN ↔ GND    （复位，镊子短接）
SW2  QSPI_SS ↔ GND   （BOOTSEL，镊子短接）
```

## 做不了的项目

**50Ω 射频线的阻抗**没法用万用表测，需要 TDR 或矢网。这块板的射频走线全在 F.Cu、
以 In1 为参考面，阻抗由介质厚度决定。嘉立创下单时没勾阻抗控制选项，所以是按
默认层压做的——实际表现只能等贴完片用信号验证（能不能收到 1090 报文）。
