# VNA 校准 / 转接板（2 层 · 华秋免费打样档）

一块给 NanoVNA 用的板载 SOL 校准件 + U.FL/SMA 转接板。

    生成：~/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/Current/bin/python3 tools/gen_cal_board.py
    产物：kicad/cal-board.kicad_pcb        95 × 92 mm，2 层，1.6mm

## 为什么要做它

U.FL 没有现成的 SOL 校准件，校准面只能停在 VNA 的 SMA 口，**尾线（pigtail）
留在测量链路里**。2026-09-04 实测：V4.4 板 J6 读到 11.45pF，理论只有 1.6pF，
差 7 倍，一度以为板子坏了 —— 实际是尾线没被校准掉。

尾线对读数做**两件**事，只记住第一件就会误判：

| | 后果 |
|---|---|
| **相位旋转** | R/X 重新分配，X 过零的频率被挪动 |
| **损耗衰减** | \|Γ\| 被拉向圆心，**SWR 被压得偏乐观** |

同一根尾线（往返 0.55dB）：天线（|Γ|=0.04）SWR 1.083→1.089 可忽略；
开路线（|Γ|=0.885）SWR 10.84→**16.40**，压低了三分之一。

有了这块板，就能把尾线**真正校准进 VNA**，而不是事后补偿。
（软件补偿仍可用：`hardware/tools/vna_deembed.py`，只需一次尾线空接读数。）

## 板上有什么

```
┌─ 1) U.FL SOL ─────────────────────┬─ 3) THRU / adapters ─┐
│  J1 OPEN   J2 SHORT   J3 LOAD     │  J7─J8  UFL-SMA 7.5mm│
├─ 2) SMA SOL ──────────────────────┴──────────────────────┤
│  J4 OPEN   J5 SHORT   J6 LOAD                            │
│  J9─J10 UFL-UFL 3.5mm      J11─J12 SMA-SMA 14.0mm        │
└──────────────────────────────────────────────────────────┘
```

| 区 | 用途 |
|---|---|
| **① U.FL SOL** | **核心**。校准 `SMA母–IPEX` 这类尾线，校准面落在 U.FL 接触面上，与实际插 J6/J7 时完全一致 |
| **② SMA SOL** | 校准 `SMA母–SMA母` 尾线。**如果 NanoVNA 自带 SMA 校准件，这三组可以不焊** |
| **③ THRU / 转接** | U.FL↔SMA 转接、S21 归一化、验证线缆损耗 |

## 设计上的三个硬约束

**① 参考面必须一致 —— 这是校准板的命根子。**
Short/Open/Load 到连接器焊盘的距离必须相同，否则三者不在同一参考面，
解出来的误差模型是错的。本板做法是**零长度**：标准件直接贴在信号焊盘边上。

    OPEN   信号焊盘悬空（只有焊盘自身的边缘电容）
    SHORT  紧邻打 3 个过孔到底层地（多孔并联压低短路电感）
    LOAD   紧邻贴 2×100Ω 0402 并联（并联把寄生电感减半）

**② 走线长度分两档处理。**
1090MHz 在这个叠层上的波导波长是 150.4mm，**λ/20 = 7.5mm** 是分界：

| 组 | 走线 | 线宽 | 依据 |
|---|---|---|---|
| UFL-UFL | 3.45mm | 1.20mm | 电长度不足 9°，阻抗偏差可忽略 |
| UFL-SMA | 7.47mm | 1.20mm | 刚好卡进 λ/20 |
| SMA-SMA | 14.0mm | **2.40mm** | 超过 λ/20，须按 50Ω 走 |

⚠️ 2 层 1.6mm 板的 50Ω 线宽是 **2.692mm**（由嘉立创 2 层官方数据点
h=1.43/W=2.6916/50Ω 反标定 Dk=4.423 算得）。但 **SMA 垂直座四个地脚之间
只有 2.83mm 净空**，留 0.2mm 间距后最宽只能走 **2.43mm**。取 2.40mm（53.0Ω）
是这个几何硬限与阻抗之间的折中，不是随手写的数。

**③ 走线端点不能落在 U.FL 焊盘中心。**
U.FL 封装自带 `top_keepout` 规则区，其右边界离信号焊盘中心只有 0.535mm，
而走线端帽是圆的（半径 = 线宽/2）会伸进去。端点内缩 0.35mm，
既仍与焊盘重叠导通，又让端帽退出禁布区。

## 怎么用

**校准 U.FL 尾线**（把尾线纳入校准面）：

1. VNA 设好频段（如 950–1200MHz）
2. 尾线 SMA 端接 VNA PORT1，U.FL 端依次插 **J1(OPEN) → J2(SHORT) → J3(LOAD)**
3. 每插一个，在 NanoVNA 的 CAL 菜单里点对应项，最后 DONE + SAVE
4. 之后直接插主板的 J6/J7，读数就是板上真实值，**不用再 de-embed**

**验证**：校准后插 J1(OPEN)，Smith 图应落在最右（开路）；插 J2 落最左（短路）；
插 J3 落圆心（50Ω）。三者都对，校准才算成功。

## 已知误差源（不追求实验室级精度时可忽略）

自制标准件的寄生量未知，NanoVNA 会按理想件处理，因此存在残余误差：

| | 量级 @1090MHz | 影响 |
|---|---|---|
| OPEN 的焊盘边缘电容 | ~0.1pF → −j1460Ω | 相对理想开路（∞）偏一点 |
| SHORT 的过孔电感 | 3 孔并联约 0.3nH → +j2Ω | 相对理想短路（0Ω）偏一点 |
| LOAD 的电阻寄生 | 2×100Ω 并联后约 0.2nH | 高频略偏感性 |

对 1090MHz 单频点的用途足够。要更准就得买带 ADAPTER 定义的商用校准件。
