# V3 布局专用飞线板

这个目录用于人工重新摆放元件，正式 PCB 不会被覆盖。

## 操作

1. 打开 `expansion-board-v1.kicad_pro`，再进入 PCB 编辑器。
2. 只移动或旋转现有封装，重点调整 U8、U10 及周边阻容。
3. 可以横放或竖放阻容；以最短关键网络、清晰电源回路和可逃逸空间为准。
4. 不修改位号、value、封装、网络、板框或层叠，也不要增删器件。
5. 暂时不要布线；保存 `expansion-board-v1.kicad_pcb` 后告知“布局已保存”。

后续会直接读取这个 PCB 中的精确坐标和旋转角度，锁定你的布局后重新布线。
