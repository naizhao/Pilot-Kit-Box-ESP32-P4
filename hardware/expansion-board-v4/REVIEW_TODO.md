## 0. 下单工艺参数【必读，选错会毁板】

### 0.1 过孔处理：塞树脂 + 电镀盖帽

勾「盘中孔：需要」+「过孔塞树脂 + 电镀盖帽」。板上过孔盘 0.45mm、
U19 EP 的 via-in-pad 0.50mm，都 ≤0.5mm，满足该工艺的尺寸要求。

需要它的原因是 **EP 散热孔**：`U19`(SY6970) 的 EP 里有 9 个 0.30mm 钻的
via-in-pad，不塞树脂的话回流焊锡会顺孔流走，EP 焊不牢 = 散热失效。
`U8`/`U10`/`U18` 的 EP 锡膏按 3×3 均匀网格 60% 开窗——**塞孔盖帽之后 EP
表面是平的，锡膏开窗不需要避开过孔**（这一条我绕了三轮才确认，
嘉立创工艺页原文：「为防止贴片时锡膏流入孔中……需要做树脂塞孔(树脂+盖冒电镀)
工艺，保证焊盘表面平整，该工艺要求过孔直径小于等于 0.5mm」）。

### 0.2 ⚠️ 但 J4 的 4 个 SH 焊盘绝不能塞

`J4`(USB-C) 的 4 个 `SH` 是**通孔焊盘不是过孔**：⌀0.60mm 钻、1.00×2.10 /
1.00×1.60 盘，是插进去焊锡固定座子的机械脚。**被当过孔塞了树脂，USB-C
插拔几次就会把座子拔下来。**

判据是**阻焊层**，工厂按它区分，本板已经是对的：

| | 钻孔 | F.Mask / B.Mask | 工厂如何处理 |
|---|---|---|---|
| `J4.SH` ×4 | 0.60mm | **开窗** ✅ | 普通 PTH 焊盘，正常上锡 |
| `J4` 定位柱 ×2 | 0.65mm | 开窗（NPTH） | 不金属化，不上锡 |
| `U19.25` ×9（EP 散热孔）| 0.30mm | **不开窗** ✅ | 按过孔塞树脂盖帽 |
| 其余 386 个过孔 | 0.30mm | 不开窗 | 同上 |

改动 J4 封装或全局阻焊设置后，**必须重新确认 SH 仍然开窗**。
`check_route.py` 里有断言守着这一条。

### 0.3 提交格式：交 KiCad 工程，不要交 Gerber

嘉立创工艺页写明：「如果是 gerber 文件，此选项中选项无效，**一律按文件过孔属性
生产**」。交 Gerber 的话上面的过孔处理选项会被忽略。

## A. ~~测试点~~【已执行 2026-08-23】

**决定：删掉 TP1–7 + SW1，只保留 SW2。**

判据：这 7 条网络除了测试点没有第三方节点——DEMOD0–3(GPIO20–23) 和
RECOVERED_CLK(GPIO24) 是固件里 PIO 解码状态机往外**输出**的调试信号，
不在接收链上（接收链是 AD8313 → TLV3501 比较器 → PULSES → GPIO19）。
固件调试在已打样的 v3.2 上做，那块板的 TP 和解调链与本板完全相同
（`expansion-board-v3/tools/sheet_mcu.py:95` 逐条一致）。

保留 SW2 的理由：它是唯一的强制刷机入口（USB UF2）。

| 指标 | 改前 | 改后 |
|---|---|---|
| 飞线总长 | 3100mm | **2640mm** (−15%) |
| 飞线交叉 | 834 处 | **612 处** (−27%) |
| 元件数 | 182 | 174 |
| B 面中间 | TP 列占着 | 完整让给电池 955465（65×54） |

#### SW2 最终位置：西板边 (51.85, 81.05) B 面，出电池投影区【2026-08-28 定案】

第一次搬迁的理由是**电池铝壳短路**，不是信号完整性：

`SolderJumper-2_P1.3mm_Open_Pad1.0x1.5mm` 的两个焊盘是 **1.0×1.5mm 裸露开窗
铜箔，没有阻焊覆盖**。原位置（U8/U9 之间）在电池投影区内，软包锂电的铝外壳
压上去把 A/B 两盘一搭 → QSPI_SS 被拉到 GND → RP2040 每次上电都判定进
BOOTSEL → **板子永远起不来**。这是确定性失效，不是概率问题。

##### 位置演进：中间 → 东侧 → 西板边（当前）

| 版本 | 位置 | 为什么改 |
|---|---|---|
| 初版 | U8/U9 之间 (84.96, 85.72) | 追求最短 stub |
| 二版 | 板东侧 (129.60, 91.90) | **躲电池铝壳短路**（见上） |
| **当前** | **西板边 (51.85, 81.05)，B 面，转 90°** | **老虎钳要能从板边咬住**——夹在板中间够不着 |

⚠️ 坐标是**板坐标系**，x=51.85 在西边。但 SW2 在 B 面，B 面视图左右镜像，
所以「挪到东边」这个说法和这个坐标不矛盾。**看 B 面的东西时先想清楚是哪个坐标系。**

焊盘边缘距西板边 **1.15mm**（焊盘 rot=90 后板坐标占 1.5×1.0mm），钳口够得着。

##### 由此产生的 38.75mm stub —— 算过，无害（且比二版更好）

| | 二版（B.Cu 东行） | **当前（In2 西行）** |
|---|---|---|
| stub 长度 | 46.2mm | **38.75mm** |
| 走线层 | 外层 B.Cu，一面暴露 | **In2 带状线**，上有 In1(GND)、下有 In3(3V3平面)，双面屏蔽不辐射 |
| 路径 | 穿电池投影区下方 | **绕开电池** |
| 距射频最近 | — | 1.41mm，但**异层**且中间隔完整 In1 GND 平面 |

2026-08-27 的 review 我把二版那条 stub 标成 🔴「可能偶发启动失败或读 Flash 出错」，
**那个结论是错的**，量级上站不住。按当前 38.75mm / 带状线重算：

| 项 | 数值 | 对比余量 |
|---|---|---|
| 附加电容 | 走线 5.35pF + 焊盘 0.57pF = **5.9pF** | — |
| 边沿变缓 | τ=50Ω×5.9pF=0.30ns，t_r 增加 **0.65ns** | 占 setup 余量 9% |
| stub 单程延迟 | 38.75mm × 6.9ps/mm = **267ps**（带状线 v=1.45e8） | — |
| 振铃衰减 | 往返 534ps，几个来回 ≈ **2ns** | — |
| W25Q128 要求 tSLCH | 5ns | RP2040 实际给 **7.5ns**（66MHz XIP 半周期）|

2ns 振铃 vs 7.5ns 余量，差 3.7 倍。集总/分布判据也偏向无害：RP2040 QSPI
默认 slow slew，t_r≈2.4ns，**t_r/6 = 400ps > 267ps → 按集总电容处理即可，
连传输线都算不上**；即使固件开 fast slew（t_r≈1ns）刚过线，余量仍有 3 倍。

**我当初判错的根因**：把它当成「挂了个按钮的 stub」。SW2 是
`SolderJumper_Open`，**出厂默认断开**，末端是开路的一段线，不是负载。
开路 stub 和挂负载的 stub 是两回事，我按后者的直觉写了结论，没算数。
⚠️ 引用自己早先写下的理由时，要连同当时的前提一起复核。

真正参与每次取指令的主干（U8.56 ↔ U9.1 ↔ R6.2）只有 **6.8mm**，
和其他 QSPI 线同量级，没被拉长：

```
QSPI_SS    45.52mm  ← 其中 38.75mm 是开路 stub，主干仅 6.8mm
QSPI_SD0   18.30mm      QSPI_SD3   12.91mm
QSPI_SCLK  14.29mm      QSPI_SD1    7.90mm      QSPI_SD2    7.20mm
```

软件入口 `picotool reboot -u` 依然是首选，物理短接算兜底。

**如果将来要加回测试点**：`sheet_mcu.py` 里 GPIO20–24 的网络名保留着（没标 NC），
补一句 `s.place` 即可。

### v4 相对 v3.2 的新变量（跟测试点无关，但要留意）

v4 的 B 面多了两颗开关电源（SY6970 充电 1.5MHz、SY7069 升压 1MHz），
v3 是纯靠微雪供电的。开关噪声会耦合进 `3V3_RF`，而那正是 AD8313/
TLV3501 的供电——**v4 可能出现 v3.2 上不会出现的接收灵敏度下降**。

1. 软件遥测：RSSI(ADC1)、LEVEL_BIAS(ADC0) 本来就接在 RP2040 的 ADC 上，

3. 解调波形：探 U15.5(PULSES)，那是 SOT-23-6 的引脚，能直接搭表笔

## D3. 【要你定】电源区阻容封装：0603 → 0805？

**结论先行：电容该换，电阻不用。** 但关键理由不是散热。

**电阻**——电源区的电阻功率都极小，0603（额定 100mW）余量充足：

| 位号 | 值 | 实际功率 | 0603 余量 |
|---|---|---|---|
| R43 | 1k（VBUS 9V → VDD 3.3V）| (9−3.3)²/1k = **32.5mW** | 3 倍 ✅ |
| R38 | 180Ω（ILIM 电流镜参考）| mW 级 | ✅ |
| R41/R42 | 470k/150k（FB 分压）| 5V/620k = 8µA → **0.04mW** | ✅ |
| R37 | 6.8k（CFG1 档位）| µA 级 | ✅ |

**电容**——问题不在散热，在**直流偏置下的容值衰减**和**耐压可得性**：

1. **DC bias 衰减**：同容值同耐压，0805 的介质体积比 0603 大约一倍，直流偏压下容值
   衰减小得多。10µF/16V X5R 在 5V 偏压下，0603 可能只剩 3~4µF（−60%），
   0805 还有 6~7µF（−30%）。开关电源的输出纹波直接受这个影响。
2. **耐压可得性**：**C72 要 6.8µF/25V，0603 封装买不到**——0603 在 25V 档容值上限
   通常只有 1~2.2µF。它接 9V 侧（PD 诱骗后），耐压不能降，只能放大封装。

**建议**：C72 → 0805 或 1206（先确认能买到 6.8µF/25V）；C73/C74/C75(10µF) → 0805；
C70(47nF) 保持 0603（容值小，无 DC bias 问题）；C76/C77 已经是 1206 ✅。

⚠️ 换封装会改变 B 面布局（0805 比 0603 大 0.9×0.65mm），功率回路要重新验证间距。
**没你确认我不动。**

## D4. 电池温度检测（已定案 2026-08-23）

**保留 NTC，改用贴片。** 三条依据：

1. **不能删**——SY6970 的 TS 是锂电池充电安全强制项。<0°C 充电析锂（枝晶刺穿隔膜、内短路，
   最危险的失效模式），>60°C 加速老化/热失控。不接就得用固定电阻假装永远 25°C，等于关掉保护。
2. **80°C 不是问题**——TS 保护只管充电路径：高温停充，但 PMID→SYS 直供和 BAT→SYS 放电都不受限，
   **设备照常运行**，降温自动恢复充电。反倒是去掉 NTC 才会在 80°C 继续充电。
3. **必须贴片**——电池用 3M 胶直接贴 B 面，板面与电池零间隙，插件玻璃头放不下。

选型 `NCP18XH103F03RB`（Murata 0603 10k 1%）或 TDK `NTCG163JF103FT1` / 国产 0603 10K 1%。
B 值差异已核：3428K(B25/85) vs 103AT-2 的 3435K，差 0.2%，**R39/R40 不用改**。

⚠️ **装配注意**：3M 胶导热系数低（普通 VHB 约 0.2 W/m·K），会带来热延迟。
电池温度变化本来就慢，常规保护够用；若要更快响应，把 NTC 正上方那一小块换成**导热双面胶**。
