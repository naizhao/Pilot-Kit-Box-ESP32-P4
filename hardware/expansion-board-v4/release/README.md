> 🔴 **V4.10 相对 V4.9 有两处会让人读错板的改动：**
> `J11` 从 2x8 贴片排针改成 **2x10 裸焊盘阵列**（配 2x10p 测试夹，**不贴任何件**），

## V4.10 / V4.9 相对 V4.8 的功能性差异

**一处：调试口 `J11`（V4.9 是 2x8 贴片双排排针；V4.10 已改为 2x10 裸焊盘阵列）。**

板上此前**没有任何办法接触 CC1312R 的 cJTAG**——`U8`(RP2040) 与 `U10`(CC1312R) 之间
`SUBG_TMSC`/`SUBG_TCKC`/`SUBG_RESET` 三根点对点直连，中途既不能断开也无处下探针，
「ROM SSI 与 cJTAG 同时无响应」时分不清是 RP2040 时序问题还是 CC1312 本身问题。
J11 把这三根引出来，并顺带取代了原来的 `TP1`~`TP7` 与 `SW1`/`SW2`（那 9 个已删除）。

```
 1 VHF_TCXO_TP     2 VHF_AUDIO    ← pin1 经 R66（0Ω，默认不贴）才接 26MHz 参考
 3 VHF_SCK         4 VHF_SDATA
 5 GND             6 RP_RUN       ← 短接 5-6 = RP2040 复位
 7 GND             8 QSPI_SS      ← 短接 7-8 = BOOTSEL（UF2 刷机）
 9 SUBG_TMSC      10 SWCLK
11 SUBG_TCKC      12 SWDIO
13 SUBG_RESET     14 DEMOD0
15 GND            16 DEMOD1
17 DEMOD3         18 DEMOD2
19 RECOVERED_CLK  20 PULSES      ← 短接 19-20 = 自检回环
```

裸焊盘**没有跳线帽可插**，三对短接用镊子或锡桥。19-20 那对做自检回环时
**必须先拆 `R57`**，否则 TLV3501 的推挽输出与 GPIO 对驱（见固件 `selftest_gen.h`）。
B 面丝印：**20 格对照表**（每格 = 脚号 + 缩写，如 `5 GND`、`8 BOOT`）直接印在
`J11` 正上方、离座子顶端 2.4mm；`J11` 位号夹在表和焊盘之间锁定归属
（没有单独的 "J11" 标题文字，归属由「图例必须紧挨 J11」的合同断言守住）。
**丝印用的是缩写**（`RUN`/`BOOT`/`TMS`/`TCK`/`RST`/`RCLK`/`PLS`…），
缩写 ↔ 完整网络 ↔ 原 TP/SW 位号的完整对照表在 [`PINMAP-zh_CN.md`](../PINMAP-zh_CN.md) 的「J11 调试焊盘阵列」一节。
其中最容易搞混的两个：**`RUN` = 原 SW1（复位）**、**`BOOT` = 原 SW2（BOOTSEL）**。

## V4.8 相对 V4.7 的功能性差异（V4.9 一并继承）

两处，V4.7 都没有，**与 V4.7 不可混用**。

**① GNSS 备份供电** — `U23` / `C101` / `C102` / `D7` / `R63` / `BT1`，且 `U7.pin6`
已由 `3V3_GNSS` 改接 `GNSS_VBAT`。关机后 GNSS 模块保住 RTC 与星历，不再冷启动。

**② 指示灯** — `D8` 电源（3V3_DIG 常亮，关机自灭）、`D9` 充电（接 SY6970 的
`STAT` 开漏脚：充电中亮、充满灭、**故障时 1Hz 闪**），各配 1k 限流（`R64`/`R65`）。
不占任何 GPIO。两灯摆在 X+ 壁 USB-C 与电源键之间，外壳需在该壁配套开孔。

## 单面 SMT 后的手焊/核对项

| 位号 | 件 | 为什么不进 SMT |
|---|---|---|
| `BT1` `J9` `RT1` | 备份电池 / 主电池座 / NTC | 三者都在 **B 面**、不进当前任何 CPL；F 面 SMT 后手焊 |
| `D8` `D9` | 0805 LED | `max CPL`（及配套 BOM）有推荐型号；常用 `full` 方案不含，使用自备料时手焊 |

⚠️ `D8`/`D9` 只能用 **Vf 2.0~2.2V** 的红 / 黄 / 橙 / 普绿。蓝、翠绿、白的 Vf 是
3.0~3.1V，挂 3.3V 轨上点不亮——充电灯还要再扣 `STAT` 的 0.4V 饱和压降，只剩 0.2V。
两颗的位号和全板其余 238 个一样印在 **F.Silkscreen、字高 0.8mm**，
板面直接可读；封装自带的阴极标记线也在，极性照它焊。
装配图 `ASSEMBLY_MAP-V4.11-zh_CN.pdf` 可作交叉核对。

C100 添加前的同名两包已保存在 `archive/20260913-before-c102/`，不可用于新订单。
