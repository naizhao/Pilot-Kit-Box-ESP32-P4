## 关于「过孔看不见孔」（历史说明；当前v4尚无布线过孔）

**这是正常的，不是缺陷。** 板规里明确设了过孔两面盖油：

```
(tenting (front yes) (back yes))    ← 过孔正反面盖绿油
(covering (front no) (back no))     ← 没有做树脂塞孔
```

最终v4若继续采用盖油，原因有两个：

1. **防盗锡**——过孔不盖油，回流焊时旁边焊盘的锡会顺着孔被吸走，造成虚焊
2. **防短路**——0.3mm 的裸铜孔露在外面，装配时掉进一根锡丝就短路

盖油只盖表面那层，**孔壁的镀铜是通的**。对着强光看，盖油的过孔会透出一点亮点；
用指甲划过能摸到一个个小凸起。

真正肉眼能看见的孔是那 4 个 ⌀2.7mm 安装孔——它们是 NPTH（非金属化），孔壁没有镀铜。

要确认过孔到底通不通，别靠看，做下面的**阶段 2**。

## 阶段 1：电源对地绝缘（历史测试点，待按最终v4重算）

**万用表用电阻档，不要用通断档**——通断档只会"响/不响"，看不出 100kΩ 这种半短路。

裸板上这些**必须全部开路**（读数 ∞ 或 >10MΩ）：

| 测这两点 | 探哪个焊盘（挑的是大焊盘，好下探针） | 期望 |
|---|---|---|
| GND ↔ VCC_5V | `U10.49`(5.2mm 散热焊盘) ↔ `J1.1` | 开路 |
| GND ↔ 3V3_DIG | `U10.49` ↔ `U9.8` | 开路 |
| GND ↔ 3V3_RF | `U10.49` ↔ `U14.1` | 开路 |
| GND ↔ 3V3_GNSS | `U10.49` ↔ `Q2.2` | 开路 |
| GND ↔ RP_1V1 | `U10.49` ↔ `C28.1` | 开路 |
| GND ↔ SUBG_VDDR | `U10.49` ↔ `C60.1` | 开路 |
| VCC_5V ↔ 3V3_DIG | `J1.1` ↔ `U9.8` | 开路 |
| 3V3_DIG ↔ 3V3_RF | `U9.8` ↔ `U14.1` | 开路 |

> `U10.49` 是 CC1312R 的 EP 散热焊盘，5.2×5.2mm，是全板最好探的 GND 点。

**任何一对读数低于 1MΩ 就停手**，是层压错位或钻孔毛刺，直接找嘉立创换板，别贴片。

## 阶段 2：网络连通（历史测试点，待按最终v4重新生成）

用通断档。下面每一对的连接路径都**必须穿过内层或底层**，也就是说测通了就等于
证明过孔是通的。这是验证过孔最直接的办法（比拿放大镜看强）。

### 电源网络（跨整块平面，验证 In3 电源层和 In1/In4 地层）

| 网络 | 测这两点 | 距离 | 走线层 |
|---|---|---|---|
| GND | `J5.2` ↔ `J4.SH` | 94mm | In1 + In4 |
| 3V3_DIG | `R3.1` ↔ `C65.1` | 76mm | **In3 电源平面** |
| 3V3_RF | `C52.1` ↔ `C38.1` | 82mm | F + In2 + B |
| 3V3_GNSS | `U3.5` ↔ `R18.1` | 70mm | F + In2 |
| VCC_5V | `C2.1` ↔ `D1.1` | 34mm | F |

> **3V3_DIG 那条要重点看。** 这块板的 In3 是 3V3_DIG 电源平面，设计过程中出过
> 「平面上走信号导致铜皮碎成 14 块」的问题（已修）。实板测这两点，是对修复结果
> 的最终验证。

### 信号网络（每条都跨 ≥2 个铜层，必然经过过孔）

| 网络 | 测这两点 | 距离 | 走线层 |
|---|---|---|---|
| RF_DET_OUT | `R35.1` ↔ `R21.2` | 见最新板 | F + In2 + B |
| LEVEL_BIAS | `R33.1` ↔ `C49.1` | 53mm | F + In2 + B |
| GNSS_TXD | `U7.2` ↔ `J1.36` | 50mm | F + In2 |
| USB_CC2 | `R8.1` ↔ `J4.B5` | 50mm | F + B |
| BIAS_EN_1090 | `R18.2` ↔ `U8.4` | 50mm | F + In2 |
| SUBG_TMSC | `U10.24` ↔ `U8.27` | 44mm | F + In2 + B |
| BIAS_EN_978 | `Q2.1` ↔ `U8.5` | 44mm | F + In2 + B |

全部应该 **<1Ω 导通**。挑其中 4-5 条测就够，不用全测——过孔是同一道工艺出来的，
抽样代表性足够。

## 阶段 3：贴片回来之后

裸板过了以后再做，这里先列出来，到时候展开：

1. **上电前**再测一次阶段 1 的电源对地——这次不该是开路了，但也不能是 0Ω。
   短路（<10Ω）说明贴片时有连锡。
2. **限流上电**：实验电源限流设 100mA，5V 加到 `J1.1`。正常应该只吃几十 mA。
   一上电就顶到限流 → 立刻断电查短路。
3. **分级量电压**：`3V3_DIG`(U9.8) / `3V3_RF`(U14.1) / `3V3_GNSS`(Q2.2) /
   `RP_1V1`(C28.1) / `SUBG_VDDR`(C60.1) 逐个量，都在标称 ±5% 内。
4. **RP2040 枚举**：USB-C 插电脑，按住 `SW2`(BOOTSEL 焊盘，镊子短接) 上电，
   应该出现 RPI-RP2 U 盘。
5. **调试口**：~~TP1/TP2 接调试器~~ —— **V4 已删除 SWD 测试点**（2026-08-23）。
   需要 SWD 时从 RP2040 引脚 `U8.24`(SWCLK) / `U8.25`(SWDIO) 飞线，
   或直接在已打样的 v3.2 上做（那块板保留了全部 7 个测试点，电路逐条相同）。
6. **解调输出**：~~TP3~TP7 接示波器~~ —— 同上已删除。
   DEMOD0–3 / RECOVERED_CLK 是固件里 PIO 状态机的**调试输出**，不在接收链上
   （接收链 AD8313 → TLV3501 → PULSES → GPIO19）。硬件问题探 `U15.5`(PULSES) 就能看出来；
   要看解码质量用软件遥测 RSSI(ADC1) / LEVEL_BIAS(ADC0)。

### IFA 专项（制造尺寸同步并完成布线后才执行）

1. J7接VNA，**C53不贴**；先保持ZS1=0R、ZP1/ZP2=DNP，记录S11最低点和X=0频点；
2. 从画长52.0mm主臂的开路端向50.2mm名义目标逐刀切，每次切0.1–0.2mm，记录每刀后的
   频率、R、X和dF/dL；完整六层rev2模型仅预估0.1mm约升1.98MHz，实测不应拿它作硬判据；
3. 装盒并按量产位置固定后复测；V1历史实测的装盒下移范围是8–20MHz，不能写死30MHz。
   H2分别使用量产金属螺丝和不装螺丝/尼龙螺丝做A/B，记录频率、R/X和报文变化；
4. 需要匹配时可从ZP1 DNP、ZS1 3.6nH、ZP2 3.3pF起扫，并备3.6/3.9pF，最终值以装盒VNA为准；
5. 最后实收1090报文，并用J6外接天线做报文数、距离和噪声底A/B。VNA匹配不能代替效率验收。

### 测试点速查

```
SW2  QSPI_SS ↔ GND   （BOOTSEL，镊子短接后上电 → 电脑出现 RPI-RP2 U 盘）
```

**V4 只剩 SW2 这一个焊盘。** TP1–TP7 与 SW1 已于 2026-08-23 删除，
判据是那 7 条网络除测试点外没有第三方节点（详见 REVIEW_TODO.md A 节）。
需要探测时的替代位置：

| 原测试点 | 信号 | 现在探哪里 |
|---|---|---|
| TP1 / TP2 | SWCLK / SWDIO | RP2040 引脚 `U8.24` / `U8.25` 飞线；或直接用 v3.2 |
| TP3–TP6 | DEMOD0–3 | 固件的 PIO 调试输出，**不在接收链上**。硬件问题探 `U15.5`(PULSES) |
| TP7 | RECOVERED_CLK | 同上；要看时钟恢复用 v3.2 |

> ⚠️ **DEMOD0–3(GPIO20–23) 与 RECOVERED_CLK(GPIO24) 现在是悬空网络**——
> TP3–TP7 是它们**唯一**的第三方节点，测试点删掉之后这 5 条网络只剩 RP2040 一端，
> 板上没有任何可探的落点。这不是漏接：它们本来就只是 PIO 状态机往外抛的调试位，
> 固件不依赖它们工作。真要看，用保留了全部 7 个测试点的 v3.2。
| SW1 | RP_RUN 复位 | R5 已把 RUN 上拉到 3V3；复位靠断电或 `picotool reboot` |

接收链的完整信号流：`AD8313 → SLICER_FAST → TLV3501(U15) → PULSES → RP2040 GPIO19`，
门限由 `GPIO25/TL_PWM → R34 → LEVEL_BIAS → R33 → SLICER_LEVEL` 闭环控制，
`RSSI`(ADC1) 与 `LEVEL_BIAS`(ADC0) 都能被 RP2040 直接读回——**优先用软件遥测，别急着上示波器**。

## 做不了的项目

**50Ω 射频线的阻抗**没法用万用表测，需要 TDR 或矢网。这块板的射频走线全在 F.Cu、
以 In1 为参考面，阻抗由介质厚度决定。v4下单必须选JLC06161H-3313并勾选阻抗控制；
若漏勾，这批板不能再按0.15mm≈50Ω的设计前提验收。最终仍要用VNA和1090报文A/B验证。
