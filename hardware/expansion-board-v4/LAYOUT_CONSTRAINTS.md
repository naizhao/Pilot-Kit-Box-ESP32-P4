# 扩展板 V4 — PCB 布局布线约束（阶段 4 依据文件）

> 板厂/叠层锁定：嘉立创 **6 层 JLC06161H-3313** 阻抗叠层（成品约1.54mm，外层1oz，
> L1–In1 介质3313约0.0994mm）。50Ω 单端微带线参考线宽 **0.15mm**（官方正算0.1509mm，L1参考In1，
> 介质 3313 0.0994mm/Dk4.1 → 0.1509mm = 50.00Ω）。
>
> ⚠️ 旧值 **0.34mm 是 4 层 JLC04161H-7628**（L1-L2 介质 0.21mm）的。`96fc34e` 转 6 层后介质
> 薄了一半多，同一线宽实测只有 **31.82Ω**（官方计算器反算），偏低 36%。失配的馈线不只是损耗，
> 它会把天线的谐振读数一起拖走——2026-08-21 查 IFA 时才发现。
> **下单必须勾「阻抗控制」**，0.15mm 已属细线，不勾没有 ±10% 保证。
> 层规划：**F.Cu 信号+RF / In1 完整 GND参考面（IFA全层净空除外）/ In2–In4 电源与信号回流 /
> B.Cu 信号**。实际层名以 `.kicad_pcb` 为准。
>
> **IFA 预研边界（2026-08-24）**：保持当前图形与方向，候选最终主臂**50.2mm**
> （历史D=5.0三点插值50.187mm，按PCB实际D=4.988/H=6修正为50.230mm）、画板52.0mm；
> 馈电脚中心线端点后先保留0.750mm等宽端帽，
> 再从真实铜边做1.500mm的1.5→0.15mm完整渐变，随后以约2.853mm的0.15mm微带接ZP1，
> 总路径约5.103mm。
> 该尺寸、taper、π网络和IFA两网微带已同步PCB；仍待实板验证，见
> `../expansion-board-v3/IFA_HFSS_2026-08-24.md`。

## 0. 工程内已固化的规则（`.kicad_pro` net_settings）

| 网络类 | 线宽 | 间距 | 归属网络 |
|---|---|---|---|
| RF50 | **0.15mm** | 0.15mm | ANT1090_IFA、IFA_MATCH、1090/978、LNA/SAW、检波、SUBG、GNSS RF 网络 |
| POWER | 0.5mm | 0.2mm | USB_VBUS、VCC_5V |
| POWER_LO | 0.25mm | 0.15mm | 三路 3V3、RP_1V1、SUBG_VDDR、熔丝后馈电 |
| Default | 0.15mm | 0.15mm | 其余 |

> 上表来自当前 `.kicad_pro` 的 `net_settings`。若文档与工程冲突，以工程为准；
> **0.34mm 是四层旧值，在本六层叠层约为31.82Ω，禁止用于 RF50。**

⚠️ **RF50 的 clearance 必须保持 0.15mm**，不可设成 0.3mm：0.5mm pitch 的 QFN48/DFN-8
封装内部相邻焊盘天然只有 0.22–0.25mm 间隙，设大会产生无法满足的 DRC 报错。
**共面波导（CPWG）的信号-地间隙是布线时按阻抗计算器设定的几何参数，不是网络类最小间距。**
IFA的0.15mm线按In1参考的纯微带计算；ZS1两侧必须各用一个独立F.Cu规则区，在线边
每侧禁铜0.50mm并禁过孔，不能用一个含两个不连续岛的zone。In1参考地不得挖空。

## 1. 总体分区（俯视，J3 排母面向主板）

```
┌────────────────────────────────────────────────────────────┐
│ J1(2×20 排母, 与主板 J3 对插)          GNSS 区: U7+J2(U.FL) │
│ 电源区: U1-U3 LDO                      [尽量远离 RF/DCDC]   │
│ 传感器区: U4(BNO085) U5(BMP388)                             │
│   QMC5883P → 磁洁净区(距电感/DCDC/大电流环路 ≥10mm)          │
│ RP2040 + Flash + USB-C(板边)     CC1312R 区: U10+匹配+J5    │
│ ── 1090 RF 链（沿板边一条直线，严禁折返）─────────────────── │
│ J6(U.FL)→偏置Tee→U11→FL1→U12→FL2→C34→U14→切片器→(PULSES→RP2040)    │
└────────────────────────────────────────────────────────────┘
```

## 2. 1090 RF 链（最高优先级）

1. **链路直线布置**，输入到检波器单向推进，任何一级不得跨越另一级上方/下方走线。
2. 全链 50Ω 受控阻抗（F.Cu，参考 In1 GND）；级间连线尽量短（目标每段 <8mm）。
3. **级间隔离**：LNA①输入段与 LNA②/检波段用 GND 过孔墙分隔（过孔间距 ≤λ/20@1.09GHz ≈ 2.5mm，实操 1.5mm 栅栏）；SAW 输入/输出两侧不得平行走线。
4. TA0970A 的 A 长地焊盘（2.2mm）下方打 ≥3 个 GND 过孔。
5. ~~AD8319/AD8313 双封装位~~ —— 2026-08-26 删除 AD8319(U13) 与其温补电阻 R20，AD8313(U14) 为唯一检波器。
   现行约束：**U14 输入脚迎信号源、输出脚朝下游**（MSOP-8 两侧分列，装反会让两头都绕本体）；
   52.3Ω 差分端接 R19 与 3pF 的 C35 紧贴输入脚；COMM 就近多过孔接地。
6. MM8930 产测座：land/阻焊严格按 O30E 标准图（封装已按原图复核；DFM 阶段再核阻焊细节），两侧 50Ω 渐变线按图收窄至 0.8mm 馈线宽。
7. 检波器输出（RF_DET_OUT）之后是"准模拟低频区"：切片器 RC 网络紧凑放置，远离 PULSES 数字回程；LEVEL_BIAS/RSSI 可走非RF信号层。
8. 屏蔽罩预留：RF 链 LNA①→检波段外围画 TE 2118716-2 框（16.5mm）丝印+焊盘，V1 不焊罩。

## 3. 978 段

1. CC1312R 的 lattice balun（L9/L10/C40/C44）元件对称紧贴 RF_P/RF_N 引脚，差分段 <5mm。
2. DCDC 电感 L7（6.8µH）与 C60 紧贴 pin33，"低电感接地"（TI 原注）——C60 地过孔 ≥2 个直下 In1。
3. **L7 属于磁洁净区排除对象**：与 QMC5883P 距离 ≥15mm。
4. 48M 晶振走线 <5mm，包地；32k 晶振远离 DCDC 开关节点。
5. J5 附近 D3(ESD) 先于 C39 靠天线端。

## 4. 三天线口与共存

- J6(1090)/J5(978)/J2(GNSS) 三个 U.FL **分置三个板角**，彼此间 GND 过孔墙。
- GNSS RF_IN 走线独立短直，远离 RP2040 QSPI（谐波密集）与 USB。
- 偏置 Tee 的 PMOS/保险丝/100nH 属直流侧，可放B.Cu；射频馈电节点回到F.Cu受控阻抗线。
- IFA 天线本体下方六层全部禁铜；馈线一出净空区，In1参考面必须立即恢复。
- J7测IFA时C53不贴；π网络默认0R/DNP只代表直通，不代表已经匹配。

## 5. 数字区

1. RP2040：QSPI Flash 走线 <15mm 等长不强求；晶振包地；USB DP/DM 90Ω 差分（0.2/0.2 参考 JLC 表）短直到 USB-C。
2. PULSES（比较器→GPIO19）是关键采样信号：单根短直、包地，不与 QSPI/USB 平行。
3. SUBG SPI + cJTAG 束走非RF信号层，长度不敏感（≤10MHz）。
4. USB-C 开口方向：**待外壳干涉检查**（docs/jlc/lcd-4.3in/3d-case 的 v2 薄壁盒），先按板右侧边缘出口布置。
5. J1 排母 40 脚全部过孔直通，孔位与微雪 J3 逐脚镜像核对（HAT 对插方向！画板后用主板实物比对一次）。

## 6. 电源与地

1. In1 作为连续 GND 参考面；除 IFA 全层禁铜区外不分割，RF 回流全部就近走 In1。
2. 三路 LDO 分区供电：3V3_RF 走线单独从 U2 拉到 RF 链，不与 3V3_DIG 共享路径；各芯片去耦电容 0402 贴脚。
3. BMP388 上方外壳留通气孔（结构侧动作，板上无铜即可）。

## 7. 磁洁净区（QMC5883P）

- 与以下保持距离：L7 DCDC 电感 ≥15mm、任何 >100mA 电流环路 ≥10mm、螺丝孔/钢件 ≥8mm。
- 传感器下方所有铜层禁走大电流；参考地完整。

## 8. 板框与结构

- 板框为 **100×62mm**；J1 排母位置与微雪载板 J3 相对位置逐脚对齐（关键！）。
- 固定孔 4×M2.5，位置避开磁洁净区。
- 外壳开孔（USB-C、三个 U.FL）与 3d-case v2 的干涉检查 = 投板前置门。

### 8.1 电池投影区内禁止出现裸露铜箔

软包电池 955465（65×54）平放在 B 面中部，**铝外壳是导体且直接贴着板面**。
阻焊覆盖的走线没问题，但任何开窗裸铜落在它下面 = 被铝壳搭上 = 短路。

已按此约束定位的元件：

| 位号 | 封装 | 落点 | 短路后果 |
|---|---|---|---|
| `SW2` | `SolderJumper-2_P1.3mm_Open_Pad1.0x1.5mm` | 西板边 (51.85, 81.05)，B 面 | QSPI_SS 拉到 GND → RP2040 每次上电进 BOOTSEL → **板子永远起不来** |

`SW2` 还有第二条约束：**必须贴着板边**。它是要用老虎钳咬住短接的调试点，
夹在板中间钳口够不着。当前焊盘边缘距西板边 1.15mm。
（坐标是板坐标系；SW2 在 B 面，B 面视图左右镜像，所以它看起来在"东边"。）

⚠️ 这条约束**脚本查不出来**——DRC 只管铜箔之间的间距，不知道板子上方会压一块
金属。将来加任何 SolderJumper / 测试焊盘 / 免阻焊标记，都要人工核对落点。
为躲开它而付出的走线代价要单独评估，不要反过来用信号完整性推翻它：
SW2 这次的代价是 46mm 开路 stub，算下来余量仍有 3.7 倍（见 `REVIEW_TODO.md` 「A.」）。

## 9. 布局验收（每次挪完元件都要跑）

### 9.1 电气归属：元件有没有待在它该待的地方

```bash
~/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/Current/bin/python3 \
  tools/check_affinity.py            # 只列超标；加 --all 连合格的一起看
```

判据：每个 R/L/C/Q/D 都有一个**电气锚点**，离锚点太远就是错位。

| 归属方式 | 怎么定锚点 |
|---|---|
| 串联 | 该件串在两个节点之间 → 锚点只认 **U 芯片 / J 连接器**，不认相邻的 RLC |
| 专属 | 该件所有信号网络只通到一颗 U → 锚点是那颗 U |
| 单端 | 只有一个信号网络（旁路/去耦）→ 锚点是同网最近的 U |
| 链路+N跳 | 直连网络里没有 U/J（匹配网络的中间节点）→ 沿网络 BFS 到第一个 U/J |

阈值**按网络性质分档，不能一刀切**：

| 档 | 限值 | 依据 |
|---|---:|---|
| RF | 5mm | 1090MHz 在 FR4 里 λ≈100mm，5mm 已是 0.05λ |
| ANALOG | 12mm | 高阻抗节点（判决门限、AGC、检波输出）怕拾噪，不怕相移 |
| DIGI | 25mm | `BIAS_EN` 这种开关信号拉 30mm 也没事 |

两个反直觉的地方，改判据前先读一遍：

1. **锚点只认 U/J**。若退而取「最近的邻居」，整片网格一起漂移时内部互相都在
   2mm 内、全判合格，而整片飘在板子另一头——978 匹配网络就是这么漏掉的。
   同理才要有「链路+N跳」这条，否则 `SUBG_N3/N4/N5` 这些 RLC 接 RLC 的中间
   节点永远查不出来。
2. **名字带 ANT/RF 的未必是射频**。`ANT_SEL_*` 是 GPIO；`*_FUSE`/`*_FEED` 是
   bias-tee 的**直流侧**（射频已被扼流圈挡在另一边），Q3/F3 贴着 F3 是对的。
   不排除这些会满屏假红。

### 9.3 底层教训

**整齐 ≠ 正确。** 按位号排出来的网格跟「谁属于哪条链」毫无关系：
L17 离 U20 的 LX 30mm 是它（见 `project_power_loop_vs_tidy_grid`），
978 匹配网络绕 20mm 再折回也是它，C35 离检波器 33mm 还是它。
自动布局能排得很好看，但它不知道电流从哪来、到哪去。
